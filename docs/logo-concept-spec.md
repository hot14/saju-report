## 1. 원천 문법 해부 (b6cde5b)

| 관측 | 값 | 로고로 가져올 규칙 |
|---|---|---|
| 스트로크 | 균일 중간 굵기, 벡터 패스 질감 | 굵기 편차 0. 도형 전체에 스트로크 1종만 |
| 교차 처리 | 교차점마다 깔린 실(under)이 끊겨 보임 | 엮임은 겹침이 아니라 끊음으로 표현한다. 끊는 간격 = 스트로크 폭의 1.5배 |
| 루프 형태 | 원호와 눈물꽃 모양(꽃잎) 루프 | 루프는 원호+반전 곡선의 조합만. 각진 꺾임 금지 |
| 대칭 | 개체별 방사 대칭(주 4절), 정사각 셀 안 배치 | 마크는 정사각 캔버스 안 4절 대칭을 기본으로 한다 |
| 구성 | 여러 닫힌 세그먼트가 모여 하나의 매듭 | 단일 닫힌 경로가 원칙(3안 모두). 실이 끊기지 않는다는 것이 매듭의 정의다 |

**프레이밍 경계(필수):** 매듭의 전통 상징(장수·복·행운)을 마케팅 문구로 쓰지 않는다. 금지 어휘 체계와 같은 이유다. 본 마크의 서사는 구조다: 여덟 글자를 하나의 실로 엮어 사람의 패턴을 계산한다. 술(tassel)과 술방울은 매듭의 본질이 아니므로 마크에 포함하지 않는다(v2 수집 참고 태그의 술 지배 이미지들은 문법 추출에서 제외, INDEX.md 사용 규칙 3).

**문화 근거:** 한국 매듭은 옷고름·노리개의 실용 장식 전통이다. 유사 교차 문법이 인접 문화권에도 있으므로(판창 계열), 3안의 형식은 옷고름 매듭의 루프 비율을 준거로 차별화하고 ja·zh 로케일에서 부적으로 오인되지 않는지 i18n 검수 항목에 넣는다(§6).

## 2. 공통 설계 파라미터 (3안 전부)

- 캔버스: 정사각 viewBox `0 0 100 100`, 마크는 내접 여백 12 이상(최소 76x76 사용)
- 스트로크: `stroke-width: 6` 고정, 라운드 캡·라운드 조인트, 색은 먹 `#1B1B1E` 단색
- 반전 규칙: 한지 배경 위 먹선이 기본. 먹 배경 위에서는 한지색 선으로 반전만 허용(다크 테마가 아니라 시그니처 밴드용)
- 골드 `#B98A2C`: 마크 본체 금지. 공유 카드 잉크 밴드 안 시그니처 용도로만 예외 허용(tone 가이드 §2.4 승계)
- 교차 끊음: 모든 under 교차에서 간격 9(= 1.5 x 6)로 위 실이 아래 실을 끊는다
- 스케일 게이트: 16px 파비콘에서 루프 개수와 엮임이 살아야 한다. 16px에서 붕괴되면 루프 수를 줄여 재설계한다
- 애니메이션: 결정론 리빌만 허용(MOTION 4). 실이 그려지는 순서는 항상 같다(같은 입력 = 같은 시퀀스, P1)

## 3. 3안

### A안 · 넉잎 매듭 (four-petal single-strand knot) · 기본 상징 후보

- **구조**: 단일 닫힌 경로가 중앙의 마름모(정사각을 45도 회전)를 감싸고, 네 변에서 바깥으로 눈물꽃 루프 1개씩을 내민다. 루프 4개 + 중앙 코어 = 4절 방사 대칭. 교차점은 상하좌우 4곳, 각각 under 끊음 적용.
- **기하 스케치**: 코어 마름모 꼭짓점 (50,32)(68,50)(50,68)(32,50). 각 꼭짓점에서 바깥 루프: 제어점 (50,8)(92,50)(50,92)(8,50) 방향으로 원호 Q 2개가 눈물꽃을 완성. 전체는 `M 32 50` 에서 시작해 4개 루프를 순회하는 단일 경로.
- **의미 구조**: 네 기둥(사주의 년·월·일·시)이 중앙의 하나(사람)를 엮는 구조. 설명 문구는 "네 기둥, 하나의 실".
- **용도**: 앱 아이콘, 파비콘, 푸터 워드마크 옆 심볼. 16px에서 코어+루프 4개가 유지된다.
- **장단**: 가장 작은 곳에서 가장 잘 산다. 대형 전개에서는 단순함이 심심해질 수 있어 C안과 병행.

### B안 · 여덟길 매듭 (eight-crossing cosmos knot) · 시그니처 후보

- **구조**: 둥근 사각 프레임(모서리 반경 18) 안을 단일 실이 지그재그로 3회 통과하며 여덟 글자(사주팔자)의 여덟 교차점을 만든다. 교차 8곳에 순서대로 over-under를 교차 배치하면 실은 위상학적으로 하나로 이어진다.
- **기하 스케치**: 프레임은 둥근 사각 (14,14)-(86,86). 실의 경로: 좌상단 (14,26) 에서 시작해 우하단으로 하강, (86,50) 에서 반사, (14,74) 로 하강 후 상승, (50,14) 에서 하향 관통, (50,86) 에서 상승 복귀해 시작점과 닫는다. 각 방향 전환은 라운드 조인트로 루프 없이 꺾는다.
- **의미 구조**: 여덟 교차 = 여덟 글자. 계산이 실을 엮어 하나의 그림을 만든다는 서사와 직결.
- **용도**: 공유 카드 잉크 밴드의 시그니처, 결제 신뢰 라인 끝의 인장.
- **장단**: 서사가 가장 강하다. 단 16px에서 교차 8곳이 뭉개지므로 파비콘으로는 부적합하고, A안과의 병행이 전제다.

### C안 · 고름 격자 매듭 (norigae lattice knot) · 확장 마크 후보

- **구조**: 2x4 격자(세로 2칸 x 가로 4칸, 사주 4기둥 x 천간지지 2줄의 배열)의 각 칸에 코너 루프 1개가 살고, 단일 실이 지그재그로 8칸을 모두 관통해 닫는다. 칸의 코너 루프는 A안의 눈물꽃을 축소한 형태여서 계열 통일이 된다.
- **기하 스케치**: 격자 칸 크기 18x36(가로 x 세로), 시작점 (14,32). 실은 칸의 대각선 방향으로만 이동하고 칸 경계마다 코너 루프로 방향을 반전한다. 교차는 칸 사이 통과점 7곳.
- **의미 구조**: 입력 화면의 8슬롯과 1:1 대응된다. 계산 중 화면에서 칸이 하나씩 채워지는 결정론 리빌의 그래픽 원형이 된다.
- **용도**: 계산 중 화면의 8슬롯 프레임, 로딩 인디케이터(진행 바 금지 원칙의 대체재), 결과 화면의 한자 격자 배경 뼈대.
- **장단**: 제품 구조와 직접 연결되는 유일한 안. 단독 상징으로는 복잡하므로 A안의 확장 시스템으로 위치한다.

### 채택 권고

A안을 기본 상징, C안을 제품 내 확장 마크로 병행 채택을 권고한다. B안은 공유 카드 시그니처 후보로 보류하되, 16px 붕괴 문제가 해소되는 대형 용도로만 검토한다. 3안 모두 b6cde5b 문법(균일 스트로크·끊음 엮임·루프) 위에 있으므로 최종 선택이 계열을 깨지 않는다.

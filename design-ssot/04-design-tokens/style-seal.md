# 일간 오브제 스타일 봉인 시트 (Illustration Style Seal)

목적: 물상 배지 ×10의 먹선 일러스트를 외주·AI 생성 어느 쪽으로 만들든 획·질감·채색이 흔들리지 않게 고정한다. 이 문서 한 장이 계약서의 스펙 조항이다.
상태: **봉인 시안 미완** - 아래 규칙으로 시안 10종을 만들어 이 폴더(`04-design-tokens/seal/`)에 확정본을 봉인한 뒤 발주한다.
원천 레퍼런스: `assets/minhwa_art/` · `assets/ink-wash/` · `assets/ink-illustration/` (채택 태그 카테고리만 참조)

---

## 1. 획 (Stroke)

| 항목 | 규격 |
|---|---|
| 획 굵기 | 오브제 실제 폭 기준 2.5~3.5% 단일 계열. 굵기 변주는 시작-끝 테이퍼로만 |
| 획 수 | 오브제당 외곽선 1본 + 내부 세부선 6본 이하 |
| 색 | 다크 배경용 #F5F1E6 단색 먹선 (채색은 별도 레이어) |
| 마감 | 뾰족한 끝 처리 금지. 둥근 캡(round cap) |
| 금지 | 스케치 라인, 해칑, 이중 외곽선, 그라데이션 획 |

## 2. 질감 (Texture)

- 먹 번짐은 오브제 **내부에만** 5% 이하로 허용 (배경 번짐 금지 - 배경은 화면 토큰이 관할)
- 질감 표현은 한지 섬유 느낌의 미세 노이즈 1종으로 통일. 브러시 텍스처 사본 투입 금지
- 다크/라이트 양쪽에서 동일 실루엣이 인식돼야 한다 (라이트용 반전 자산 별도 납품)

## 3. 구도 (Composition)

| 항목 | 규격 |
|---|---|
| 캔버스 | 정사각 1024×1024, 오브제 실제 폭은 캔버스의 62~70% |
| 여백 | 상하좌우 균등. 시선 중심은 정중앙에서 ±3% 이내 |
| 방향 | 오브제의 "성장 방향"은 우상향 통일 (나무·불꽃·상승물), 고정물(산·돌)은 정면 |
| 시점 | 3/4 측면 금지. 정면 또는 완전 측면 중 오브제별 1회 결정 후 10종 일괄 동일 |

## 4. 채색 (Coloring)

- 채색은 오행 계열 1색 + 명도 2단계 (양간 짙게/음간 밝게). 제3색 금지
- 채색 범위는 오브제 면적의 40~60%. 선은 항상 크림 먹선 위에 최상단
- 색상 코드: DESIGN.md §2 오방 팔레트 + 보조 천간 팔레트(tokens.css) 사용

## 1. 관찰된 문체 원칙 7가지

1. 자연물 은유 먼저: 일간을 성격 설명이 아니라 자연물 이미지로 정의하고, 그 이미지에서 성격을 끌어낸다. 제니 해설이 壬(양의 수)를 넓은 바다·거센 강 이미지로 연 뒤 성격을 전개하는 식이다(실측: 지시서 §4.1 인용부).
2. 두 문장 확장: 은유 정의 다음에는 "큰 꿈", "적응력"처럼 같은 이미지 안에서 성격 단서 2개를 덧붙인다(실측: 지시서 §4.1).
3. 오행 과다·부족의 조언 전환: 분포 불균형을 결함이 아니라 행동 지침으로 바꾼다. 화가 부족하면 "스스로 빛을 줄이지 마세요" 같은 격려형으로(실측: 지시서 §4.1 규칙 3).
4. 낮은 점수의 미개봉 서사화: 궁합 점수가 낮아도 부정으로 끝내지 않고 "아직 안 그려진 자리"로 재해석한다(실측: 지시서 §4.2 인용부). 이것이 이 서비스의 감정 안전장치다.
5. 해요체 기본, 이모지 절제: 해설은 해요체로 통일하고 이모지는 섹션 기호 수준(🌊·💞·🀄)으로만 쓴다(실측: `site/ko/idol/jennie-blackpink.html` H2 목록).
6. 한자 병기: 전문 용어는 한자를 괄호로 곁들이되 해설 본문은 한글 독음으로 흘린다. 예: "대운(大運)", "일간(日干)", "오행(五行)"(실측: 제니 페이지 H2, FAQ 질문).
7. 층위별 말투 분리: 서비스 해설은 해요체, 팬 다이어리(UGC)는 구어체 반말 1인칭이다(실측: `data/blog.json` ko 제목, "승관은 틀림없이 불(火)일 거라 확신했어" 어투).

## 2. 점수 밴드 서사 규칙

궁합 점수는 해설 가능한 밴드로 나뉘고, 각 밴드에 고정 서사가 붙는다(실측: `site/ko/blog/gunghap-score-guide-what-71-80-90-96-mean.html` H2).

| 밴드 | 서사 방향 | 해설 포인트 |
|---|---|---|
| 60~79 | 상극을 "긴장의 끌림"으로 재해석 | 서로 다른 점이 마찰이 아니라 자극이라는 프레임 |
| 80대 | 상생에 가장자리(현실 마찰 요소)를 얹기 | 완벽하지 않아서 생기는 이야깃거리 제시 |
| 90 이상 | 모든 것이 맞아떨어짐 | 과장 대신 차분한 확언, 지나친 단정은 피함 |

설계 의도 [추정]: 어떤 점수가 나와도 실망 문장이 나오지 않도록 밴드 자체를 서사로 설계했다. 100점 만점제를 쓰는 서비스는 이 표를 반드시 함께 설계해야 한다.

## 3. 템플릿 1: 일간 풀이

대상: 아이돌 프로필·본인 사주 결과의 핵심 문단. 분량은 4~6문장.

```
[구조 슬롯]
1. 정의: "{일간} 일간이에요. {자연물 한 명사}이자 {보조 이미지}죠." (1문장)
2. 확장: 그 이미지가 행동으로 번역되는 문장 2개. 서로 다른 성격 단서 2개.
3. 관찰 전환: "남들이 {부분}을 볼 때 당신은 {전체}을 봐요" 같은 대비 구문 1개.
4. 오행 조언: 가장 부족한(많은) 오행 1개를 골라 격려형 지침 1문장.
5. 링크 훅: 같은 일간·같은 띠 콘텐츠로 이어가는 안내 1줄.
```

자체 작성 예시(甲木, 양의 나무):

> 갑목(甲木) 일간이에요. 곧게 뻗은 큰 나무이자 새싹이 돋는 가지죠. 한 방향으로 자라는 힘이 있어서, 정한 일은 끝까지 밀고 가요. 주변이 흔들려도 줄기는 서 있죠. 다만 목(木)이 많으면 고집이 굵어지니, 가끔은 가지를 다듬는 유연함이 필요해요. 같은 갑목인 아이돌도 만나보세요.

채움 규칙: 자연물은 일간 10개마다 1개씩 고정 매핑(甲=큰 나무, 乙=화초, 丙=태양, 丁=촛불, 戊=산, 己=밭, 庚=도끼·쇠, 辛=보석, 壬=바다, 癸=이슬). 은유는 풀이 전체에서 일관되게 유지하고 중간에 이미지를 바꾸지 않는다.

## 4. 템플릿 2: 궁합 결과

대상: 매칭 결과 화면과 카드. 분량은 3~5문장 + 라벨.

```
[구조 슬롯]
1. 대형 점수(숫자) → 관계 라벨 1개 (예: 60대="빈틈의 인연", 80대="흐름의 인연"처럼 자체 명명)
2. 원소 관계 한 줄: "{내 오행}이 {상대 오행}을 {상생/상극 동사}하는 사이" + 짧은 감각 부연
3. 띠 코멘트 한 줄: 두 띠의 합·축 관계를 가볍게, 이모지 1개
4. 마무리: 위로형·확장형 1문장. 낮은 점수면 §2의 미개봉 프레임 적용
5. 액션 버튼 4개: 카드 저장, 자랑하기, 링크 복사, 전체 리딩
```

자체 작성 예시(72점, 목×금):

> 72점, 빈틈의 인연이에요. 나무가 쇠를 다듬는 사이, 서로를 갈아주는 관계예요. 다듬어지는 쪽은 아프다고 느낄 수도 있어요. 🐯와 🐭는 서로를 보듬는 조합이라 위로가 되죠. 점수가 다는 아니에요. 아직 서로에게 쓰지 않은 페이지가 남았다는 뜻이기도 해요.

채움 규칙: 라벨은 점수 밴드별로 미리 12개 이상 정의해 두고 결정론적으로 선택한다(같은 점수면 같은 라벨). 상극 관계는 "누르는", "갈아주는" 같은 상호작용 동사로 쓰고 "부딪히는", "망가지는" 같은 소진 동사는 쓰지 않는다.

### 5.2 팬 다이어리형 (UGC 관점)

실측 구조(승관 팬 다이어리, `site/ko/blog/fan-diary-theo-the-drummer-ran-seungkwans-saju.html`): 제목이 서사 전체를 압축한다("틀림없이 불(火)일 거라 확신했어. 점수: 67. 그는 안개였어."). 본문 H2는 "67. 스팀과 스파크." 같은 점수 콜아웃과 "癸 — 그는 안개였어" 같은 일간 반전, 마지막에 팬 댓글. 즉 1인칭 예측이 데이터에 의해 뒤집히는 반전 구조다.

```
[구조 슬롯]
1. 제목: "나의 예측 + 점수 + 반전" 3단 압축. 반말 구어체.
2. 서두: 최애 생일을 찾은 계기 1~2문장 (실화 톤)
3. 전개: 오행·일간을 성격 서사로 치환. "금(金)은 차가운 방식으로 정밀해요" 식으로
   원소를 성격 부사로 쓴다.
4. 반전: 점수·조합 수치를 그대로 인용하며 예측과 결과의 갭을 보여준다.

```

## 6. 금지 규칙과 법적 경계

1. 확정 단정 금지: "반드시", "틀림없이 ~다"는 해설 본문에 쓰지 않는다. 팬 다이어리의 인용부 예측은 예외(서사 장치).
2. 엔터테인먼트 면책 동봉: 사주 해설이 들어가는 모든 페이지에 오락 목적 면책문을 둔다(혼빛도 전 페이지 기재, 지시서 §5.1·§7).
3. 원문 복제 금지: 혼빛 문장을 그대로 옮기지 않는다. 밴드 서사, 라벨 체계, 은유 매핑은 자체 재정의한다.
4. 실명 데이터 주의: 아이돌 실명·생일 기반 콘텐츠를 상업화할 경우 출처 표기와 초상권 검토가 선행된다(지시서 §7).
5. 수치 왜곡 금지: 점수, 밴드 경계, 조합 수치는 계산 결과를 그대로 쓴다. 서사가 수치를 바꾸지 않는다.

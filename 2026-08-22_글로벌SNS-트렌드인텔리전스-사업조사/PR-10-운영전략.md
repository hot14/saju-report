## 2. 기관급 리포트 표준 템플릿 (핵심 산출)
### 구조 (매 호 고정)
1. **Executive Summary** — 5문장: 이번 주 3대 신호, 확신도, 행동 권고
2. **지표 대시보드** — 전 주 대비: 신호 수, 급상승 키워드 TOP10, 플랫폼별 활성도, 전 대비 증감율
3. **심층 분석 1~2건** — 신호→트렌드 판단 근거 (데이터 포인트 5개 이상), 채택/기각 논리
4. **크리에이터 액션 플레이** — 이 트렌드를 콘텐츠로 만드는 구체 시나리오 3종 (훅/형식/타이밍)
5. **출처 목록** — 모든 주장-출처 1:1 매핑 표 (URL+발행일+신뢰도)
6. **2주 전망** — 시나리오 3종 (확산/지속/소멸) 각 확률과 관찰 지표
7. **방법론 부록** — 데이터 컷오프 시각, 수집 소스, 가중치, 한계 고지

### 발행 품질 체크리스트 (15항)
1. 모든 수치에 출처가 붙었는가
2. [추정] 수치가 시각적으로 구분되는가
3. 컷오프 날짜가 명시되었는가
4. 상충하는 데이터가 있다면 병기되었는가
5. Executive Summary만 읽어도 결론이 나오는가
6. 각 트렌드에 '왜 지금인가' 근거가 있는가
7. 모수 부족 신호가 과대 해석되지 않았는가 (n<3 명시)
8. 중국 소스 정보가 D등급으로 표기되었는가
9. 행동 권고가 구체적 실행 단계인가
10. 2주 전망에 검증 가능한 지표가 있는가
11. 편향적 표현(성별/지역/계층)이 없는가
12. 허가받지 않은 데이터 재사용이 없는가
13. 용어집/약어 풀이가 첫 호 대비 일관되는가
14. 이전 호 예측의 적중/빗나감 회고가 포함되었는가
15. PDF/웹 버전의 수치가 서로 일치하는가

## 3. 트렌드 분석 프레임워크
### 신호→트렌드→하입 판별
| 단계 | 정의 | 판별 기준 |
|---|---|---|
| 노이즈 | 단발 언급 | 1일 내 소멸, 1~2 소스 |
| 신호 | 반복 감지 | 24h 3개 이상 독립 소스 |
| 이머징 트렌드 | 확산 곡선 시작 | 주간 언급 +150% 이상, 플랫폼 2개+ 크로스 |
| 메인 트렌드 | 검색량 급등 | Google Trends 100% 대비 돌파, 언론 2차 보도 |
| 하입 사이클 정점 | 포화 | 증가율 둔화 + 패러디 콘텐츠 출현 (PewDiePie 신호) |
| 소멸/정착 | — | 2주 연속 감소 or 베이스라인 안착 |

지속성·확산속도·채널확산수 3축 점수화 (각 0~5점, 12점 이상 = 투자 권고)

## 4. 인플루언서 성장 플레이북 (도그푸딩)
### 자사 채널 전략: "트렌드를 만드는 사람이 아니라 가장 빨리 보는 사람"
- 포지셔닝: 매주 월요일 "이번 주 이 트렌드, 왜 터졌나" 시리즈 (리포트와 동일 IP)
- 플랫폼: 유튜브 쇼츠+틱톡 (주 3회) / X 스레드 (주 2회) / 뉴스레터 (매일)
- 훅 구조 (실증 패턴): 0-1s "이거 모르면 뒤처집니다" → 1-3s 데이터 제시 (조회수/증가율) → 3-15s 사례 2개 → 15-25s "다음 터질 것" 예측 → CTA
- 발행 빈도: 쇼츠 주 3회 이상 (성장 통계는 벤치마크 데이터로 보강 예정)
- 마일스톤: 0→1천 (트렌드 속도 경쟁, 발행량) → 1천→1만 (포맷 고정, 시리즈 IP) → 1만+ (커뮤니티 전환)
- 리포트-채널 시너지: 채널이 리포트 광고, 리포트가 채널 콘텐츠 원료 (완전 순환)

## 5. AI 콘텐츠 제작 워크플로우 (Phase 2)
신호 감지 → (LLM) 콘텐츠 기획 3안 생성 → (인간) 선정·감수 → (LLM) 스크립트+자막+썸네일 문구 → (툴) 제작 (CapCut/무료 AI 툴) → 발행 → 48h 데이터 회귀 → 프레임워크 업데이트

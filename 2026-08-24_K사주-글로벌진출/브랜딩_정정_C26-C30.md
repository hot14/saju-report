# 브랜딩 레드팀 피드백 체인 반영 (C26~C30)
적용일 2026-08-24 · 근거: 브랜딩마케팅_레드팀_handoff.md

## C26: 히어로 카피 교체
- 기존: "Korean Saju, Calculated Precisely"
- 교체: "Your Korean birth chart, explained clearly. Calculations shown."
- JA: 「韓国式四柱推命を、わかりやすく。計算過程もすべて公開。」
- 이유: 무명 브랜드가 정확성을 약속하면 과장으로 읽힘. "설명+계산 근거 제시"로 낮춤

## C27: K-정통성 프레임 완화
- 기존: "Korean authenticity" 뉘앙스
- 교체: "Shared East Asian roots, interpreted through Korean Saju practice."
- 이유: 독점 진품 주장으로 읽히면 중화권·일본에서 반발 위험

## C28: evidence tags 용어 교체
- 기존: "evidence tags" (실증 증거 뉘앙스)
- 교체: "Chart basis" / 「この読みの根拠」
- 적용: P704B 전체·P708B 랜딩·P712 리포트

## C29: 무료 리드마그넷 강화
- 기존: 3문장 텍스트 (Barnum처럼 보임)
- 교체: 시각 차트(8글자 배치+Day Master+오행 분포 도넛) + Chart basis 카드 + 1개 해석 문장
- 적용: P710B F5 단계·P708B S3 샘플 섹션

## C30: G1 게이트 강화
- 기존: 첫 유료 1건
- 교체: 비지인 유료 5건 ∧ 무료 차트 완료 50건 ∧ 결과→이메일 전환 ≥25% ∧ 치명 오류 0
- 적용: P704C G-CORE·P711A·P711E

## 채널 축소 (권고 — D+30 데이터로 확정)
- 즉시: 랜딩+계산기+이메일(핵심) / 일본어 YT+Shorts / X·note (3층만)
- 보류: Discord(이메일 300명까지) / 인스타·틱톡 EN(D+30 재검토) / 중화권·런치 플랫폼(페이즈 2)
- 이유: 1인 10채널은 과적재. 단, P706 설계는 유지하되 실행 우선순위만 조정

## 콘텐츠 가이드라인 추가
- S2 아이돌 사주: 8편당 1편 이하 + 출생시각 추정·연애·건강·사망·심리·미성년 분석 금지
- S5 Daily Element → "오늘의 기운 × 나의 Day Master" 개인화 주간 리플렉션으로 전환
- 자동화 전 컨시어지 베타: 20명 인터뷰 + 20건 수동 판매 우선 (Rimfactory 교훈)

## 런칭 시퀀스 조정
- D-21~D-0: 인터뷰·5초 브랜드 테스트·계산기 비교 콘텐츠 (사전 수요 검증)
- D+1~14: 코어 스프린트 (기존)
- D+15~21: 첫 발행 (기존) — 단, D-21부터 시드 콘텐츠 이미 유통

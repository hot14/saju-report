## 2. §4.2 팔레트 오버라이드 정당화 (한지·먹 = 실재 소재 근거)

### 2.1 문제 정의

tasteskill §4.2는 프리미엄 소비자 브리프의 "웜 페이퍼 + 브라스/클레이 + 에스프레소 잉크" 패밀리를 기본값으로 금지한다. 워커 브리프 확정 토큰(한지 `#F7F3EA` + 먹 `#1B1B1E` + 골드 `#B98A2C`)은 형태상 이 금지 패밀리와 겹친다. 따라서 오버라이드 요건("브랜드 정체성이 진짜 빈티지/장인/웜크래프트이고, 이 팔레트가 이 브랜드에 맞는 이유를 설명할 수 있을 때")을 충족하는지 문서화가 필수였고, 아래가 그 근거다.

### 2.2 근거: 팔레트가 '리치'가 아니라 '소재'에서 왔다

| 토큰 | 값 | 실재 소재 | 근거 |
|---|---|---|---|
| 한지 | `#F7F3EA` | 한지(韓紙) | 제품의 읽기 표면이 문자 그대로 '한지 위 판독'이다. P5 원칙(한지 그레인 3~6% 오버레이), 수묵화·한지 에셋 20건(판정 채택), 유료 결과 '읽기 모드'까지 소재가 먼저이고 색이 나중이다. 생랭주방 브리프에서 기본값으로 꺼낸 베이지가 아니다 |
| 먹 | `#1B1B1E` | 먹(墨) | R=G<B(27,27,30)의 살짝 찬(cool) 근흑색으로, 금지된 웜 에스프레소 계열(`#1a1714` 등)과 의도적으로 다르다. 서예 먹의 창흑(蒼黑) 톤을 따른 값이다 |
| 골드 | `#B98A2C` | 금박·금분(金粉) | 한지 문화에서 실재하는 장식 재료다. 사원 비문·불경의 금분 정전 tradition가 원천이고, `design-direction.md`가 "단청 금분" 기원으로 명시했다. 채도 62%(<80% 규정 준수) |

추가 정당화:

1. **선(先)확정성**: 이 팔레트는 tasteskill 검증 이전에 09-05 가드레일 회의에서 소재 기반으로 확정됐다. 금지 조항이 노리는 "프리미엄 브리프니까 무심코 베이지" 경로와 생성 순서가 반대다.
2. **카테고리 내 고유성**: 경쟁 실측(혼빛 다크 남보라, 포스텔러, 사주아이) 중 밝은 한지 베이스는 없다(아카이브 다이제스트 §2.6). 팔레트가 브랜드를 안 보이게 만드는 것이 아니라 카테고리에서 유일하게 식별시킨다.
3. **사용 처가 재료적이다**: 골드는 결코 배경이나 본문에 쓰이지 않고, 금박이 실제 쓰이는 자리(공유 카드 시그니처 워드마크, 시그니처 라인, 결제 강조 라인)에만 쓴다. §4.2 "남발 시 저가화"를 하드 룰로 코드화했다(§2.4).
4. **회전 규칙**: 직전 방향(V1 다크 Nocturne Obang)은 같은 골드 액센트를 다크 베이스에서 썼다. 베이스가 극적으로 교체됐고 액센트는 소재 연속성(금분)으로 유지된 것이므로 "같은 웜크래프트 팔레트 연속 2회"가 아니다.

### 2.3 대비 실측 (WCAG, 이 문서에서 계산)

| 조합 | 측정값 | 판정 |
|---|---|---|
| 먹 `#1B1B1E` 본문 on 한지 `#F7F3EA` | 15.52:1 | 합격 (AA/AAA) |
| 먹 텍스트 on 골드 `#B98A2C` 필 | 5.51:1 | 합격 (CTA 문자색은 먹만 허용) |
| 한지 텍스트 on 골드 필 | 2.82:1 | 불합격. 금지 |

### 2.4 확정 하드 룰 (오버라이드의 조건부)

1. 페이지 크롬(배경·본문)은 한지+먹 뉴트럴만. 오방색·천간색·골드는 배지·도트·시그니처·CTA 문자 이외 금지.
2. 골드 사용처: 공유 카드 시그니처, 결제 신뢰 라인 강조, (선택) CTA 문자색 대비가 확보되는 필. CTA 기본은 **먹색 단색 필 + 한지 문자**(17.18:1). v2 시드 체크리스트 "CTA가 먹색 단색인가"와 일치시켰다.
3. 배경 그라데이션 전면 금지(가드레일 §6). 한지 그레인 오버레이는 opacity 3~6% 고정.
4. 배지의 오행 5색/천간 10색은 실재 시맨틱 체계(배지=색=의미)이므로 tasteskill §9.F '장식 상태 점' 금지와 충돌하지 않는다. 단 텍스트 색으로는 절대 금지.

## 3. 대안 팔레트 1본: Olive + Brick + Paper (전환 시 즉시 투입)

오버라이드가 승인되더라도 tasteskill 요구대로 대안 1본을 스펙해 둔다. **채택 팔레트가 아니다.** 골드가 사용자 테스트에서 사치/오컬트 인상 또는 대비 문제를 일으키면 교체하는 비상 계획이다.

| 토큰 | 값 | 역할 | 대비 실측 |
|---|---|---|---|
| Paper (배경) | `#F7F3EA` 유지 | 한지. 소재 근거는 동일하게 유효 | 본문 먹 15.52:1 합격 |
| Ink (텍스트) | `#1B1B1E` 유지 | 먹 | 위와 동일 |
| Brick (단일 액센트) | `#A4472F` | CTA 필·강조. 구워낸 흙(옹기·기와)의 벽돌 적. 오방 화(火) 계열로 소재 근거 유지 | on 한지 5.39:1 합격, 한지 문자 on 필 5.39:1 합격, 먹 문자 on 필 2.88:1 불합격(문자는 한지만) |
| Olive (보조, 배지 전용) | `#6B7A4F` | 목(木) 물상 배지의 뮤트 올리브. 텍스트 아님 | on 한지 4.19:1. 대형 라벨 이상만, 본문 금지 |
| Muted (서브텍스트) | `#6F6A63` | 아래 신규 토큰 표와 공유 | 4.84:1 합격 |

전환 트리거: (a) 골드가 '점성/사치' 오인을 유발한다는 사용자 판정, (b) 골드 필의 문자 대비 보정이 레이아웃을 제약하는 경우. 전환 시 한지·먹·오방 배지 체계는 그대로이고 골드 자리만 브릭으로 치환된다. 즉 브랜드 소재 서사가 아니라 액센트 재료 하나만 바뀐다.

**기각한 대안: Cobalt + Cream.** 코발트는 오방 청(木 `#2E5A87`)과 별개의 두 번째 블루 액센트를 만들어 배지=색=의미 체계를 흐리고, 남보라 경쟁사(혼빛)의 색역 인접 부담이 있으며, 사주 카테고리에 코발트를 뒷받침할 실재 소재가 없다.

## 4. 타이포그래피 톤 룰

1. **세리프 정당화 (tasteskill §4.1)**: 이 브랜드는 §4.1이 인정하는 예외 조건("진짜 editorial / luxury / publication / manuscript / heritage")에 해당한다. 근거: 제품이 '판독 리포트'이고 읽기 표면이 한지 원전이며, 한자 그리프(壬水 등)를 텍스트로 유지하는 유일한 방법이 명조계다. 단 세리프는 히어로·카드·리딩 제목 한정이고, 본문은 마루부리/IBM Plex Sans KR, 데이터 태그는 IBM Plex Mono로 역할 분리(3본제+1)를 유지한다.
2. **Fraunces 전면 배제**: `stitch-prompts.md` 공통 접두어가 "serif display (Fraunces)"를 지시하고 있는데, Fraunces는 tasteskill §4.1에서 명시 금지된 LLM 기본 세리프다. 라틴 디스플레이는 이미 스택에 있는 Cormorant Garamond(또는 허용 풀의 Tiempos Headline급)로 대체할 것. `assets/typography/`의 fraunces.png, instrument-serif.png 표본 2건도 배제 태그 권고(수정 불가 파일이라 §9에 기록).
3. **동일 폰트 강조 원칙**: 헤드라인 내 단어 강조는 같은 폰트의 굵기/이탤릭으로만. 한글 명조 문장에 라틴 세리프 단어를 섞어 넣는 강조 금지.
4. **이탤릭 디센더**: 이탤릭을 쓰는 라틴 단어에 y/g/j/p/q가 있으면 `leading-[1.1]` 이상 + 하단 여백. (현재 스택의 Cormorant/Italiana 이탤릭 사용 시 적용.)
5. **한글 줄나눔**: `typography.css` v1.1 + `typography-linebreak-system.md` 규칙을 따른다(수정 없이 참조만).

## 5. EYEBROW 재조정 지도 (tasteskill §4.7)

기계식 상한: 화면별 `ceil(섹션수 / 3)`. 워커 브리프 override: 리포트 챕터 번호·물상 배지명·폼 라벨은 **기능 콘텐츠**로 eyebrow에 미산입.

| 화면 | 섹션 (순서) | 상한 | 판정 | 근거 |
|---|---|---|---|---|
| 랜딩 | 헤더·히어로 / 물상 배지 스트립 / 카드 프리뷰 / 마무리 CTA (4) | 2 | **유지 1**: 배지 스트립 라벨 "열 개의 물상"만. 히어로 eyebrow, 카드 프리뷰 라벨, 마무리 CTA 라벨은 제거 | 배지 라벨은 콘텐츠 분류명(기능). 히어로 eyebrow는 로케일/메타 스트립 금지 조항과도 충돌 |
| 입력 | 타이틀·생년월일 폼 / 시각 옵션 / (선택)대상 칩 / 8슬롯 (4) | 2 | **유지 0**: 전면 제거. 폼 라벨은 이미 기능 라벨 | 데코레이티브 캡스 라벨 불필요. 화면 역할이 자명 |
| 계산 중 | 단일 장면 (1) | 1 | **유지 0** | 단계 문구("태어난 해의 글자")는 콘텐츠 그 자체 |
| 무료 결과 | 정체성 카드 / 진단 본문 / 컷 블록 (3) | 1 | **유지 0**: "여기까지가 진단입니다"는 컷 헤드라인이지 eyebrow 아님. 본문 섹션 라벨("진단" 등) 제거 | 헤드라인만으로 충분. 컷 문구가 이미 기능 |

| 유료 결과 | 7챕터 + 대운 타임라인 (8) | 3 | **유지 0**: 챕터 번호·타이틀은 기능 콘텐츠(워커 브리프 명시 허용). "언제 달라지는가"도 eyebrow가 아니라 챕터 헤드라인 | 챕터 구조 그 자체가 내비게이션 |

## 6. 레이아웃·모션·형태 톤 룰

1. **다이얼 고정**: VARIANCE 6 / MOTION 4 / DENSITY 3. MOTION 4는 결정론적 리빌만(같은 입력 = 같은 시퀀스, P1). 랜덤 스피너·프로그레스 바 금지. `prefers-reduced-motion` 필수(§6.B).
2. **Shape Consistency Lock (§4.4)**: 문서화 규칙으로 해결한다. "카드·시트는 radius 0(종이 절단면), 입력 필드는 8px, CTA는 풀-필(pill)". 예외 없이 전 화면 동일 적용.
3. **Page Theme Lock (§4.11)**: 7화면 전부 라이트 한지 단일 테마. v1.5 시드의 paid_result "deep ink background (#211E1B)"는 가드레일 §1(밝은 베이스 전환)·§6(다크 배경 금지)와 충돌하므로 **폐기**. 유료 결과는 한지 읽기 모드(640px 단일 단, 16px/1.75)로 간다. 다크 야간 읽기는 별도 브랜드 승인 전까지 금지.
4. **CTA 단일 라벨 (§4.5)**: 읽기=「내 패턴 읽기」, 결제=「결제하기」, 저장=「카드 저장하기」, 공유=「공유하기». 동일 인텐트에 두 라벨 금지.
5. **리스트 UI (§4.9)**: 무료 결과 순위 리스트에 매 행 hairline 금지. 행=배지 카드 구조로. 유료 결과 7챕터는 챕터 내비(도트 레일)로 해결.
6. **여백**: 60% 이상(v2 시드 체크리스트). 밀도 3 준수.
7. **아이콘**: UI 아이콘은 허용 라이브러리만. 물상 일러스트는 아이콘이 아니라 §7 봉인 시트의 관할.

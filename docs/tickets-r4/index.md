## 1. 배경 요약

- R3에서 일러스트 봉인 시트(발주판)와 로고 컨셉 스펙 3안이 확정됐다(커밋 11cb9cf). 둘 다 "조건의 SSOT"이며 실물 제작은 별도 과제로 남아 있다(각 문서 §5 연결 필요).
- U1.5(커밋 272da71)가 먹선 스타일 7화면을 780px로 재생성했으나, 본 워커 실측(OCR·픽셀 분석)에서 **입력 화면 렌더 실패(15792px 노이즈)·워드마크 5종 난립·가격 $8/$12 불일치·결제 화면 이메일 필드 부재·컷 블록 본문 샘플 부재**가 확인됐다. 상세 근거: `docs/t14-retrial-worksheet.md` §5 · `docs/u15-usability-recheck.md`.
- P2 갱신(커밋 3dfa7ca): SajuRoot 기본 채택 임정. {{BRAND}} 치환값이 생겨 로고 병치·워드마크 정합 검수가 가능해졌다.

## 3. 순서와 연결

1. T-13·T-14는 병렬 착수 가능(서로 다른 산출물). 둘 다 "스펙 SSOT + 실물 + 검수 기록" 구조다.
2. T-15는 T-13·T-14 실물과 P2 임정 워드마크를 입력으로 받는 재생성 라운드다. U1.5에서 확인된 결함 목록(워크시트 §5)이 수용조건에 포함돼 있어, 결함을 남긴 채 재생성하면 게이트에서 반려된다.
3. 완료 판정은 각 티켓의 수용조건 체크박스 전체 충족. 기존 `docs/tickets-index.md`의 라벨·이슈 연결 규칙(§3)을 승계한다(이슈 생성은 코디네이터 몫).

## 4. 검증 기록 (본 인덱스 자체)

- 신규 파일 3건(티켓) + 본 인덱스만 생성, 기존 파일 수정 0건.
- em-dash(U+2014)·en-dash(U+2013) 전수 grep 0건.
- U1.5 결함 근거는 macOS Vision OCR 전사 + PIL 픽셀 실측 + sips 차원 측정에 기반(비전 LLM 자유 판독은 2회 상충으로 기각, 워크시트 §1 기록).

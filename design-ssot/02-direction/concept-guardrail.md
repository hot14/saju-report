# 콘셉트 가드레일 (제작 원칙 v1) · 2026-09-05 확정

> 출처: 09-05 콘셉트 가드레일 회의 + 일간 시각화 UX 회의 + 사업화 논의 (Downloads PDF 3종)
> **이 문서가 design-direction v0.1(다크 녹턴)을 폐기하고 v0.2로 전환시킨 근거다.**

## 1. 방향 전환 선언

| | v0.1 (폐기) | **v0.2 (확정)** |
|---|---|---|
| 베이스 | 다크 먹색 야간 | **밝은 한지 화이트 + 넉넉한 여백** |
| 무드 축 | 다크 셀레스티얼 에디토리얼 | **밝은 모던 K-컬처 물성** |
| 물상 표현 | 한자 오너먼트 + 천체 무드 | **'물성'의 스틸컷** (재질·점성·파쇄·흡수) |
| 리스크 | 점성학(오컬트) 톤 오인 | 오인 차단이 1순위 가드레일 |

**전환 이유**: 현재 시안이 "서양권 신비·정성·점성학 이미지"와 겹친다는 판정. 미적 완성도 문제가 아니라 **카테고리 포지셔닝** 문제 · 한 번 오컬트로 인식되면 밝은 톤으로 회수 불가.

## 2. 목표 감각: 모던 K-컬처 = 여백 · 모던함 · 밝음

- "오행/물상"을 쓰더라도 **점성학적 상징체계(별자리·신비·의식)로 해석되게 만들지 않는다** · 1순위 가드레일.
- 반동양적 + 모던 + 한국적: 전통 도상(십장생 등) 재현 금지, **선/면 중심의 현대 일러스트**로 번역.

## 3. 물성 원칙 · '형태'를 버리고 '성질'을 잡는다

상징물 전시(나무·물·흙의 뻔한 형상)는 즉시 클리셰. 물상 = **물리적 성질의 시각화**:

| 물상 | 버릴 것 | 잡을 것 (스틸컷 직관) |
|---|---|---|
| 水 물 | 흐르는 물·파도·물방울 형상 | 점성·흐름의 순간 · 표면 장력의 커브, 고임과 흐름의 경계 |
| 木 나무 | 통나무·나무 도상 | 쪼개짐·파쇄·표면결·재질의 단면 |
| 土 흙 | 흙 덩어리·산 형상 | 흡수·침투·포집의 감각 (미시 이미지: 입자 허용) |
| 火 불 | 화염 도상 | 연소의 물성 · 온도의 표면, 타고 남은 결 |
| 金 금 | 금속 도구 형상 | 광택·절삭면·경도의 표면결 |

- 행위 기반 언어(분쇄·흡수·점착)로 확장, **본체 형상은 버려도 된다**.
- 수신자에게 생소할 수 있음을 인정 → **물상별 썸네일 후보군 + 조건(제약)을 문서로** 전달 (제약 기반 창의성).

## 4. 일간 정체성 카드 (제품 1번 자산)

- 10 일간 = 하나의 일관된 세계관: 큰/작은 나무, 태양/달, 큰 산/정원 땅, 큰 금/작은 금, 큰 호수/시냇물.
- **입력 완료 → 첫 화면에서 정체성 카드 즉시 출력** ("당신은 작은 물입니다"). 첫 10초 경험이 전환 구간.
- 관계성(궁합)은 **핵심 패턴 3-5개만 짧은 장면으로** (예: 을목이 경금의 기둥을 타고 오른다). 전체 흐름도 한 장에 담기 시도 금지 · **"물상은 이미지, 해석은 텍스트"**.

## 5. 분류 노출 규칙 (사업화 결정 반영)

- 내부 정밀도는 52만 조합이지만 **사용자에게는 12-18개 핵심 유형으로 압축 노출** · 명확한 경계 + 캐릭터성 (MBTI식 좌표).
- 예외·단서가 많은 설명 금지 · 모호성 최소화가 신뢰 조건.
- 무료 = 문제의 정교한 진단+공감 / $8 = 7-8개 영역의 구체적 처방. 결제 1회로 반복 조회 가능.

## 6. 전면 금지 목록 (v0.2 강화)

**오컬트/점성학 계열 전부**: 다크 배경 히어로, 별·별자리·달 위상·천체, 성운/네뷸라 그라데이션, 수정구·타로·점성술 원반, 신비 록 신학 무드, 보라·인디고.
**클리셰 상징물**: 뻔한 나무/물/흙/불/금속 형상, 십장생 도상 재현.
**기존 유지**: 이모지, fortune/destiny/fate 어휘, 3열 아이콘 카드, 광고·구독 유도.

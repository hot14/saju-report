# 줄나눔·다국어 타이포 시스템 v1.0

> 산출물: [`typography.css`](typography.css) (프로덕션) · [`typography-demo.html`](typography-demo.html) (실동작 검증 페이지)
> 검증 완료: 390px/1280px · keep-all·strict·balance 실동작 확인 (2026-09-04, ego-browser 계산값 기반)

## 1. 원칙 (한 문장씩)

1. **단어는 끊기지 않는다** · 한글은 어절 단위(`keep-all`), 영어는 단어 단위. 글자 단위 분절은 어떤 화면에서도 금지.
2. **언어가 규칙을 결정한다** · `html[lang]`이 단일 진실원천. `:lang(ko)` / `:lang(en)`으로 각자의 줄나눔·행간·자간 적용.
3. **디바이스는 폭만 바꾼다, 규칙은 안 바꾼다** · `clamp()` 유동 타입으로 375→1280px 연속 보간. 줄나눔 규칙은 뷰포트와 무관하게 항상 유지.
4. **줄의 품질도 시스템이다** · 헤드라인 `text-wrap: balance`(리본 줄 방지), 본문 `text-wrap: pretty`(고아 단어 방지). 미지원 브라우저는 자연 강등.
5. **토큰 무결성** · `$8`, `12,400`, `Ren Water` 같은 결합 토큰은 `.price/.num/.no-break`로 분절 원천 차단.
6. **문장 구조(윤문)는 조판과 분리, 하지만 상시** · 구조는 단정·미래는 조건문 / 주장 뒤 행동 / 물상 15:85 (설계 문서 §5). 슬로프 문장은 조판이 구원하지 못한다 → 카피 검수 게이트 별도 운영.

## 2. 언어별 규칙 매트릭스

| 규칙 | 한국어 `:lang(ko)` | 영어 `:lang(en)` |
|---|---|---|
| 줄나눔 단위 | 어절 (keep-all) | 단어 (normal) |
| 하이픈 | 없음 (한글 하이픈은 오류) | 협폭 컬럼만 auto |
| line-break | strict (금지 조칙 앞 분절 방지) | 기본 |
| 행간 | 1.8 | 1.6 (디스플레이 공통 1.15) |
| 행폭(measure) | 34-42자 = `38em` | 45-75ch = `66ch` |
| 디스플레이 자간 | -0.01em | -0.02em |

## 3. 혼합 문장 규약 (한글 + 영어 런)

```html
<p lang="ko">당신의 일간은 <span lang="en">Ren Water</span> · 상위 <span class="num">12%</span> 희귀 조합입니다.</p>
```
- 한글 문장 안 영어·숫자 런은 `span[lang=en]`으로 감싼다 → 하이픈/자간이 영어 규칙, 행간은 문단 상속(이중 행간 방지 · css §6 처리).
- 역방향(영어 문장 속 한글)도 동일: `<span lang="ko">`.

## 4. 컴포넌트 계약

| 컴포넌트 | 규칙 |
|---|---|
| 히어로/헤드라인 | `text-wrap: balance` + `headline-2l/3l` 행수 가드 (최대 2-3줄) |
| 본문(리포트) | `text-wrap: pretty` + `.measure`(언어별) + `.prose` 리듬 |
| 배지·버튼·라벨·코드 | `nowrap` · 분절 원천 금지 |
| 가격·수치 | `.price/.num` · 토큰 무결성 |
| 공유 카드 | 카드 폭에서 balance 강제, 스탯 라인 `nowrap` |

## 5. anti-slop 문장 가드 (카피 게이트 · 코드 밖 규칙)

금지: 운명적·특별한·완벽하게 잘 될 것 같은 예언 어조, 과장 부사, 이모지, 느낌표 연타.
필수: 구조 설명은 단정문, 미래는 조건문("이 시기는 형태를 만드는 때입니다"), 주장 뒤 행동 묘사, 어휘는 pattern/tendency 계열.
→ 리포트 문장은 **AI 생성 후 문장 길이 편차·연접 조사 반복·군수 표현 검사를 통과**해야 조판에 들어간다 (RAG 파이프라인의 필터 4종과 별개의 표현 검수 · 보닌 검수 단계).

## 6. QA 체크리스트 (구현·출시마다)

- [ ] `$8`·숫자·고유명사 토큰 분절 0건

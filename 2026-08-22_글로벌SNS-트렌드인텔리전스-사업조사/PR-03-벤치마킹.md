# PR-03 핵심 경쟁사 벤치마킹 심층 분석 (벤치마킹 분석가 P-D03)

## 1. 심층 분석 대상 재선정 (8개)
선정 기준: 우리 정의(한국어 크리에이터 특화 + 글로벌·중국 교차 커버리지 + 저비용)와의 겹침도. PR-02 Top 15 중에서:
1. **Exploding Topics** — 트렌드 발굴 카테고리 리더, 우리의 직접 포지셔닝 경쟁
2. **Glimpse** — 무료 진입 훅의 검증된 사례 (10만+ 크롬 사용자)
3. **vidIQ** — 자사 타겟(유튜브 크리에이터)과 최대 겹침
4. **Treendly** — 초저가 구독($99/년) 가격 포인트
5. **新榜 Newrank** — 중국 통합 데이터 최강, 한중 교차 시그널 비교군
6. **蝉妈妈 Chanmama** — 더우인 + AI 스크립트 (트렌드→콘텐츠 변환 기능 벤치)
7. **PainOnSocial** — GummySearch 폐쇄 후 공백을 메우는 신생 (같은 출발선)
8. **F5Bot** — 무료 알림 인프라의 아키텍처 벤치

## 2. 서비스별 심층 카드
### Exploding Topics (미국)
- 기능: 조기 트렌드 DB, 트렌드 점수, TikTok 인사이트, Trends API
- 가격: 무료 뉴스레터 / Pro $39~249/월
- 강점: 콘텐츠 마케팅 선점(2019~, Brian Dean), 트렌드 '사전 감지' 포지셔닝, Semrush 생태계 편입
- 약점: 한국어 트렌드 미지원, 중국 SNS 0, 개인 크리에이터보다 이커머스/창업자 중심
- 마케팅: 무료 트렌드 블로그 + 뉴스레터로 SEO/리드 확보 후 Pro 전환 (우리가 채택할 모델)
- 버리는 고객: 한국어 사용자, 중국 플랫폼 크리에이터, 월 $40 미만 지불층

### Glimpse (미국)
- 기능: Google Trends 증강(실제 검색량, 관련 트렌드, 이메일 알림)
- 가격: Hobbyist 무료(10 lookups/월) / Pro $40/월 / Expert $199/월
- 강점: Chrome 확장으로 진입장벽 최소화, 132개국 기업 고객
- 약점: Google 검색 데이터에 종속 (숏폼 이머징 트렌드 포착 지연), 한국어 UI/리포트 부재
- 마케팅: 프로덕트 자체가 무료 훅, Google Trends 기능 축소를 등에 업은 대안 포지셔닝
- 버리는 고객: SNS 원시 신호가 필요한 크리에이터, 비영어권

### vidIQ (미/영)
- 기능: YouTube SEO, 키워드·트렌드 알림, AI 코치, 채널 감사
- 가격: F / Boost~Max 연 $120~
- 강점: 크리에이터 워크플로우 깊은 통합(브라우저 확장), 방대한 콘텐츠 마케팅
- 약점: YouTube 단일 플랫폼, 트렌드 '해석·리포트'가 아닌 도구 중심
- 버리는 고객: 멀티플랫폼 운영자, 트렌드 인사이트 리포트 수요자

### Treendly (이탈리아)
- 가격: F / Pro $99/년 (약 $8/월) — 초저가 구독 검증
- 강점: 카테고리별 상승 트렌드 큐레이션 단순함
- 약점: 데이터 깊이 얕음, 업데이트 주기 느림, 커스텀 추적 제한
- 시사점: '가볍고 싼 트렌드 구독' 수요 실증 → 우리 위클리 리포트 단발(1~5만원) 가격대 근거

### 新榜 Newrank / 蝉妈妈 Chanmama (중국)
- 기능: 위챗·웨이보·더우인 랭킹/이커머스 데이터, 蝉妈妈는 AI 스크립트 생성 내장
- 가격: 랭킹 일부 무료 공개 / VIP 비공개(수백 위안/월대 [D])
- 강점: 중국 플랫폼 데이터 독점적 깊이
- 약점: 중국어 UI, 결제(알리페이/위챗페이)·본토 인증 장벽, 한국어 시장 진입 0
- 시사점: "중국 트렌드의 한국어 번역·해석 리포트"는 이들이 절대 안 하는 영역 = 무경쟁 갭

### PainOnSocial (미국, 신생)
- GummySearch(폐쇄) 공백을 노리는 $19~49/월 신생. Reddit 페인포인트 AI 스코어링
- 시사점: ①폐쇄 직후 대체재가 바로 등장 = 수요 지속성 ②우리도 '공백의 대체재' 포지션 가능 (Reddit 데이터는 무료 공개 JSON/RSS만 써 계약 리스크 회피)

### F5Bot (미국)
- 무료 키워드 알림 (Reddit·HN·Lobsters), Silver $9.99(20 kw)·Gold $49.99(200 kw + RSS/JSON + AI 필터)
- 시사점: 무료 알림→유료 모니터링 업셀 구조, RSS/JSON 출력 = 우리 아키텍처와 동일 계열

## 5. 기회 세그먼트 (경쟁사가 버리는 고객)
1. **한국어 크리에이터·1인 마케터**: 모든 글로벌 도구가 비한국어. 국내 대안은 B2B 비공개 가격 → $10~30/월 구간 공백
2. **중국 SNS를 사업 기회로 보는 한국 셀러/MCN**: 新榜을 직접 쓰려면 중국어+본토 결제 → '한국어 해석 레이어' 수요
3. **GummySearch 이탈 유저(글로벌)**: Reddit 페인포인트 도구 대체 수요 (부차 타겟)
4. **트렌드 '숫자'가 아니라 '해석'을 원하는 층**: 도구는 데이터만 주고 해석은 사용자 몫 → 기관급 리포트 포지션

## honbit UX 분석 (docs/wayfinder/honbit-ux-analysis.md 작성 전 — 아래 발견을 반영해 UX 마무리)

프로젝트 내 honbit-archive/ (사용자가 새로 넣은 완전 아카이브)에서 추출한 핵심 패턴:

1. **일간 소개 = 2인칭 서사**: "당신은 乙 일간 — 음의 목이에요. 덩굴이자 들꽃 — 부드럽지만 결코 죽지 않아요." (출처: site/ko/idol/ahyeon-babymonster.html)
2. **무기 캐치프레이즈 1줄**: "당신의 무기는 부드러움으로 포장된 끈기예요." → 우리는 stems.json에 catchphrase 필드 10건 추가 필요 (원리 재구성, 근거 id 유지)
3. **오행 과다/과소 = 처방형**: "금이 부족하니 날을 세워보세요 — 경계를 더 분명히 하고…" (기존 규칙 문장 앞에 상태 리드만 붙이면 됨)
4. **결핍→관계 연결 문장**: "금 기운은 비어 있어서, 오히려 그것을 지닌 상대에게 끌리기 쉬운 사주예요."
5. **대운 = 서사형**: "9세(2015년)부터는 乙巳 대운 — 천간은 목, 지지는 화예요. 자기 목 기운이 두 배가 되는 시기라…" + 살림/누름 2종 템플릿 ("흐름이 밀어주는 편" / "저절로 되기보다 품이 드는 시기") + "— 지금" 표시. 현재 app.js는 표 형식이라 문장형 변환 필요. 판정은 dayStemVsElements 역할 라벨로 자동화 가능.
6. **FAQ 섹션** (SEO+용어 교육): 일간이 뭔가요/오행이 뭔가요/궁합 확인법 — 우리는 "일간이 뭐예요/왜 계산 과정을 보여주나요/시간을 모르면/서머타임은?" 4~6문항 details로 추가.
7. **점수→관계 서사 언어**: 89="서로를 키우는 인연", 77="불꽃 케미", 66="끌림과 긴장" (관계 읽기에 응용 가능).
8. **유료 게이트 방식** (pro.html): "최애 쪽은 하나도 안 잠갔어 — Pro에는 네 깊은 층이 들어 있어: 명식 자리 읽기·빈 오행·열두 달·시간표 16구간" — 무료/유료 경계를 명시하는 화법. #15에서 참고.
9. **푸터 고지**: "풀이는 전통 사주에 따른 혼빛의 창작입니다 — 무제휴입니다" (우리 고지문과 동일 구조 이미 갖춤).

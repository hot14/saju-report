## 2. 전 일간 공통 제작 조건

1. **색**: 먹 `#1B1B1E` 단색만. 배경은 한지 `#F7F3EA` 또는 투명. 오방색은 배지 도트(별도 UI 요소) 1점으로만 존재하고 일러스트 본체에는 무채색만 허용한다.
2. **선법 체계**: 기본은 균일 스트로크 1종(96px 캔버스 기준 3pt, 펜 압력 0). 정체성 카드 대형판만 ink-ill-04의 2중 선법(윤곽 굵선+내부 세선)을 쓸 수 있다. 크로스 해칭 금지, 평행 해칭만.
3. **농담**: 최대 3단(진먹·중간톤·여백)의 계단식. 부드러운 연속 그라데이션 금지(가드레일 §6의 그라데이션 금지를 농담에까지 확장 적용). 번짐 효과는 캐스트 그림자 가장자리에만(ink-ill-08).
4. **구도**: 단일 오브제 중앙 배치가 원칙, 오브제 점유 30% 이하, 여백 60% 이상. 예외: 표면 질감 스틸컷(병화·기토)은 프레임 전면 매크로를 허용한다(이 경우 오브제 경계선을 그리지 않는다).
5. **대칭**: 대칭 축 사용 가능. 단 ink-ill-10 문법대로 시선 점 1개는 축에서 벗어나게 둔다(배지에서는 오방 도트가 그 역할).
6. **전면 금지 (가드레일 §6)**: 천체·별·달 위상, 수정구·타로·점성 원반, 다크 배경, 십장생 등 전통 도상 재현, 원색, 사진·3D 렌더, 일러스트 내 텍스트.
7. **규격**: 원본 1024x1024 (1:1). 렌더 검증 3점: 72px(배지 스트립) · 48px(카드) · 24px(목록). 24px에서 최소 선폭이 살아야 한다(비트맵 환산 1.5px 상당). 벡터(SVG) 우선, 비트맵 납품 시 2배 레티나.
8. **계열 통일**: 10종을 한 줄로 나열했을 때 한 명의 손으로 그린 같은 계열로 보여야 한다. 굵기·간격·여백 비율의 편차를 허용하지 않는다(9·10번의 구분은 선 수와 굵기 지정으로만, §3 표 참조).

## 4. 발주 검수 체크리스트 (납품 게이트)

- [ ] 상징물 형상을 버렸는가: 누가 봐도 나무·칼·호수라는 사물로 읽히면 반려, 재질의 결·면·온도로만 읽혀야 통과
- [ ] 단일 오브제(또는 허용된 전면 매크로)이고 여백 60% 이상인가
- [ ] 스트로크 굵기가 지정 규칙(공통 2항) 안에 있는가
- [ ] 농담 3단 이내, 계단식인가. 연속 그라데이션이 없는가
- [ ] 천체·위상·타로·점성 원반이 없는가 (가드레일 §6 전수)
- [ ] 채색 0, 텍스트 0, 사진 질감 0인가
- [ ] 24px 축소 렌더에서 식별되는가
- [ ] 한지 `#F7F3EA` 위에서 먹 대비 15:1을 유지하는가 (먹 `#1B1B1E` 고정이면 자동 충족)
- [ ] 10종 나열 시 계열 통일이 유지되는가 (9·10 구분이 지정 규칙대로인가)
- [ ] EN/KR 배지 한 줄 문형(copy-deck §9)과 모티프가 같은 물성을 가리키는가

## 5. 연결 필요 (코디네이터)

1. `badge-naming-en.md` 확정 시: 배지명의 은유가 본 시트의 물성 모티프와 충돌하지 않는지 정합 체크(예: 호수 명명이면 표면장력 모티프 유지).
2. `docs/tone-alignment-guide.md` §7 초안 표와 본 문서의 관계는 승계다. 초안 쪽 수정은 불가하므로, 게이트 문서에는 본 문서를 발주 기준으로 등재해달라.
3. 배지 실물 10종 제작 후 §4 체크리스트로 검수하고 결과를 별도 검수 기록 문서로 남길 것(본 문서는 조건의 SSOT, 검수 기록은 별도).

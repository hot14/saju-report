## 2. 건별 근거 상세

### 1. 일간 대 일간 궁합법 : 확인됨

- T08-001 이론집 p256 (확정): 태극성취론을 "필요한 오행을 채워가는 과정"으로 정의. 타인과 태극을 이루는 것이 곧 궁합이자 배우자 선택이라고 위치시킴.
- T08-002 이론집 p258~265 (확정): 궁합 판단 구조 3요소가 예시 3쌍으로 전개됨.
  1. 재관 보완 원칙: 남자에게 財가 여자, 여자에게 官이 남자라서 궁합은 재관 보완 여부로 판단. 무재 남자와 무관 여자의 인연이 깊다는 규칙.
  2. 두 명조의 일간끼리 합 활용: 예시 1은 남자 辛 일간과 여자 丙 일간의 丙辛合으로 서로 없는 오행을 만들어줌. 예시 2는 甲·己 일간의 甲己合. 즉 일간×일간 합이 실제 궁합 판정 절차에 들어감.
  3. 안심법 마음 해석: 남자·여자·그 부모까지 각자 어떤 마음으로 만나는지 문장으로 풀이.
- T07-014~023 이론집 p111~114 (확정): 관계층의 일간×천간 10관계 규칙(가~차)이 체계로 존재. 궁합은 이 관계 규칙을 두 명조에 나란히 적용하는 형태라서, 45쌍짜리 전용 궁합 매트릭스표는 코퍼스에 없음.
- 참고: T02-005 p26 (확정)은 기둥별 인물 대응(년주 연상 선배, 월주 동갑 동료, 일지·시주 연하 후배)을 제공해 배우자 유형 규칙으로 확장 가능.

### 2. 천간합 끌어옴의 법칙 : 확인됨

조건표가 명시적으로 존재하며, 구조는 다음 4계층으로 요약된다.

- 끌어옴 정의·대원칙 (T05-010 p57, 확정): 불균형 사주가 합 상대의 힘을 빌려 균형을 맞추는 원칙. 끌어오는 첫 조건은 "천간은 지지에 같은 오행 뿌리가 있고, 지지는 천간에 같은 오행이 있을 때"라는 대원칙.
- 변화원리 (T05-011 p59, T05-012 p59, 확정): 5쌍(甲己·乙庚·丙辛·丁壬·戊癸)은 서로 대립하는 음양 + 서로 극하는 조합. 합이 되면 양간이 음간으로 변하고, 변한 음간이 다시 다음 합 상대와 합해 새 오행을 끌어오는 사슬 구조(예: 甲己 합으로 甲이 乙로 변한 뒤 庚과 합).
- 천간합의 방법, 조건표 4원칙 (T05-014~018 p62~63, 확정):
  1. 원칙적으로 1:1 합. 운이 와서 2:1이 되면 합이 풀린다.
  2. 원국에서 2:1은 합 불가. 운이 와서 2:2 또는 3:1이 되면 합 성립.
  3. 대운·세운에서 오는 성분은 2:1도 합 가능. 원국에 비견이 있으면 운의 합으로 비견을 제거한다고 본다.
  4. 원국 합 상태에서 운에 합 성분 하나가 더 오면 합이 풀린다.
- 끌어옴 2·3 (T05-013 p61 확정, T05-021 p65 미확인): 지지 뿌리 유무에 따라 끌어옴 성패와 형태가 달라짐. 음간이 양간을 끌어올 때는 약화(음간화)시켜 끌어온다(己土는 甲木보다 乙木을 원함).
- 풀림 해법 (T05-019~020 p64, 확정): 원국 합을 운 성분이 푸는 일반 규칙 + 양간 음간 변화가 다른 합을 풀어주는 사슬 규칙(甲己 합 성립이 乙庚 합을 푸는 식).

### 3. 대운 내부 구조 : 부분확인

- T05-001 p52 (확정): 대운은 10년 동안의 일을 근묘화실 시기와 연동해 예측, 세운은 대운 예측이 어느 해에 구체 발생하는지 판단. 대운·세운에 오는 천간에 따라 합 변화가 일어난다는 운용 전제.
- T07-047 p130 (미확인): "대운은 10년 예측, 발생 연도는 세운"을 다시 명시. 대운 지지가 뿌리를 강화(巳酉丑 등)해 끌어옴 성패를 좌우한다는 운용례.
- T09-001 p272 (미확인): 대운 10년 예측 + 세운 구체화 원칙 재확인. "대운이 좋으면 6~7년이 좋다"는 서술이 10년 내부 편차의 유일한 단서. 재운이 오기 전에는 직장생활 권고 등 운용 규칙 다수.
- T05-014 p62 (확정): 대운·세운 성분의 합 개입 규칙(위 2건과 공유).
- T02-005 p26 (확정): 대운과 별도로 원국 기둥 시간축(년 1~20세, 월 21~40세, 일 41~60세, 시 61~80세)이 존재.
- 5+5 분할: '대운 천간 5년/지지 5년' 식 규정 미발견. 대운 표기는 전부 10년 범위(예: 18~27세). 월운은 계층 용어로 정의되지 않음(월 단위 시점 언급은 T07-068 p140 미확인 정도).

### 4. 생장조건(십이운성 대응) : 부분확인

- 부재 확증: T01-006 p19 (확정) "십이운성(포태법), 왕상휴수사에 의한 천간의 강약을 논하지 않는다"고 명시. 음간 논리가 맞지 않다는 것이 사유. '생장' 단독 히트는 십이운성 단계가 아닌 일반 성장 서술뿐.
- 대응 개념 3개:
  1. 지지 뿌리 구조: 강약의 실질 판정 축은 지지 동오행 뿌리 유무 + 삼합·방합 ('뿌리' 196엔트리).
  2. 생지/왕지/묘지 3분할: T06-013 p94 (확정)의 표에서 寅申巳亥=生地, 子午卯酉=旺地, 辰戌丑未=墓地. T06-015~016 p95 (미확인), T06-017 p96 (확정)에서 24절기 기준 시작/정점/정리로 해석. 십이운성의 3단계 압축판.
  3. 근묘화실(根苗花實): T02-004 p25 (확정), T08-003 p265 (미확인). 개인 생애주기를 유년 뿌리-장년 모-중년 꽃-노년 실로 배치.
- 질적 상태 용어: 조열(4엔트리), 濁水(70엔트리), 언 물 등이 십이운성 대신 상태 서술을 담당.

### 5. 쟁합·투합 : 부분확인

- 부재 확증: 쟁합·爭合·투합·妒합 0건, 원진·귀문 0건.
- 기능 등가물:
  1. 비율 규칙(T05-014~018, 확정): 다자 경쟁 상황을 1:1/2:1/2:2/3:1 수로 규칙화. "두 개가 각자 하나씩 차지" 같은 분배 서술(C02-007#case03 p84 사례집, 확정)이 이 규칙의 실전형.
  2. 차지·빼앗김 서술: C01-008 p54 사례집 (확정)은 두 辛金이 官(丙火)을 끌어오면 남자를 연하 후배에게 빼앗긴다는 조건결론 규칙. T07-156 p200 이론집 (확정)은 庚 비견이 칼자루를 두고 경쟁한다는 서술.
  3. 비견 얽힘 → 비견 제거: 비견이 얽혀 능력을 발휘 못하는 상태를 운의 합이 풀어주는 처리(T05-018 확정, T07-137 p186 미확인).
- 즉 전통 쟁합의 "하나를 두고 다툼" 개념은 비율 규칙과 차지 서술로 재현되지만, 독립 용어·표로 정식화돼 있지는 않다.

### 6. 지지 계절과 천간 : 부분확인

- 배제 명시: T01-006 p19 (확정) 왕상휴수사 미사용. T01-002 p18 (미확인) 월령 중심 용신·격국론에서 벗어났다는 핵심 정의. T01-004 p19 (확정) 대운 흐름에 따라 판단이 변한다는 전제.
- 지지의 계절 기능: T02-003 p24 (확정) 지지는 공간 부호로 방향·계절을 담당. T06-026 p100 (확정) 지지는 방향·계절이라 물상으로 일부만 설명 가능. T06-015~017의 생지/왕지/묘지가 24절기 기준 계절 3구분.
- 월지의 실질 작동 방식: 천간(일간 포함)의 뿌리 제공 + 삼합·방합으로 기운 조절. C01-012 p50 사례집 (확정)에서 월지 巳火가 丙火의 뿌리가 되어 대운 평가를 바꾸는 식. T07-047 p130 (미확인)도 대운 지지 뿌리 강화로 끌어옴 성패가 갈림.
- 계절 효과의 표현: 점수화 없이 물상 상태 서술로 반영. 겨울에 언 물은 생명을 기르지 못한다는 물상(T03-012 p34 확정), 조열한 땅에는 뿌리내리기 어렵다는 규칙(T07-031 p121 등 확정), 탁수 조건(T03-028 p38 확정).
- 결론: 월지가 천간 강약을 매기는 전통 방식은 배제, 대신 뿌리 구조와 물상 상태 서술로 계절 효과를 처리한다. 서비스 구현 시 점수 기반 강약 대신 조건 기반 서술 규칙으로 번역해야 함.

### 7. 지역·국가 오행 : 확인됨

- 나라 오행 배정 (학설로 명시):
  - 일본 = 丙火: T03-020 p36 (확정) "국가는 일본이다", T07-160 p202 (확정) 일본(丙火)·중국(戊土) 나란히 명시.
  - 중국 = 戊土: T07-160 p202 (확정), C10-004 p482 사례집 (확정) "중국은 五行으로 戊土".
  - 미국 = 庚申: C07-010 p352 사례집 (확정) "남촌물상론에서 미국은 庚申으로 구별한다". 대륙의 戊土 + 반대편 낮의 丙火 官을 취한다는 복합 루트.
- 지구 반대편 낮밤 규칙: T03-019 p36 (확정) 火가 없으면 태양이 뜬 지구 반대편(해외)으로 가면 능력을 발휘. T07-091 p159 (미확인) 지구 반대편 밤 시간 나라 규칙. C07-010, C10-004 사례집에서 재사용. 남반구라는 용어는 0건이지만 이 규칙이 남북반구 효과를 포괄한다.
- 오행 상징 지역: 水 = 해외·유통(T03-028 p38 확정). 물이 다른 땅(나라)까지 흘러가기 때문.
- 기둥별 지역 역할: T02-005 p26 (확정) 년주 = 국가·고향, 월주 = 지역·직장. '국가자리' 23엔트리로 국가 권한·공무원·국가자격증 룰(T07-015 p111 확정 등)과 연결.
- 해외 진출 서비스 단서: 물 부족 사주의 해외 유학 규칙(C02-012 p104 등), 재운 부재 시 해외 사업 권고(T09-001 p272 미확인).

### 8. 시주 부재 시 통변 : 자료 없음

- 시주 히트는 T02-005 p26 (확정) 1건뿐. 시주 = 자녀, 61~80세 시기, 연하(후배)라는 역할 설명이 전부.
- 시각 미상 처리 규칙 부재 확증: '시간을 모'/'미상'/'자정'/'출생시' 모두 0건. 실전사례 120건 전부 출생시각이 명기된 명조.
- 판정: 이 코퍼스 안에서는 학파 고유의 시주 미상 통변 규칙을 원문 근거로 세울 수 없음. 서비스에서 3주(년월일)만 있는 사용자를 다루려면 자체 설계가 필요하며, 이는 근거 없는 확장으로 명시 고지해야 함.

## 3. 추가 과제

### 안심법(眼心法)의 운운 계층 적용 : 확인됨(범위 명시, 체계 문서는 후속 예정)

- T00-004 p4 (확정): 안심법은 2단계 고유 관법. 명조만 보고 마음을 읽고, 래정법으로 내담자 방문 목적을 알며, 궁합에서는 두 사람의 마음을 읽는 관법.
- T08-002 p258 (확정): 궁합 예시에서 상대방은 물론 그 부모의 마음까지 해석. 그리고 "대운이나 세운에 따라 어떤 마음으로 살아가는지" 읽을 수 있다고 대운·세운 적용을 명시. 안심법 본격 통변은 별도 출간 예정이라 명시(즉 이 두 책만으로는 완전 체계 아님).
- 관계층 결합 패턴: T07-017 p112 (확정), T07-085·086 p156 (확정)처럼 물상 관계 서술에 "안심법으로 보면 …하는 마음" 문장이 붙는 형식이 반복됨.
- 사례집 적용례: 직업 마음(C02-006 p76), 승진·공무원 마음(C02-008 p88), 연애 결혼 마음(C07-006 p332), 재혼 마음(C09-014 p468, C10-003 p478) 등 전부 확정.
- 월운: 계층 규칙 없음. 월 단위 시점 언급은 T07-068 p140 (미확인) 수준.
- 서비스 함의: 안심법을 "원국 + 대운/세운 시점 + 두 명조 비교"의 마음 문장 생성 레이어로 구현하는 것은 원문 근거가 충분. 월 단위 마음 해석은 근거 없음.

## 4. 서비스 규칙 후보 목록

1. 합 엔진 코어: 1:1 합 원칙, 원국 2:1 불가, 운 개입 시 2:2/3:1 합, 운 성분 2:1 합 가능, 원국 합 + 운 성분 도래 시 풀림 (T05-014~018).
2. 끌어옴 엔진: 5쌍 합 사슬(양간 음간화 후 재합), 음간의 양간 약화 끌어옴, 지지 뿌리 대원칙, 풀림 사슬 (T05-010~021).
3. 강약 처리: 십이운성·왕상휴수사 배제(T01-006). 지지 뿌리 유무 + 생지/왕지/묘지 + 조열·탁수 등 질적 상태 조건으로 대체.
4. 계절 처리: 월지는 뿌리 제공·삼합 방합 기운 조절로 모델링하고, 점수 강약 대신 물상 상태 서술 조건으로 출력.
5. 궁합 엔진: 두 명조 병렬 입력 → 재관 보완 검사(무재남×무관녀 등) → 일간×일간 합 검사 → 태극 완성체 여부 → 안심법 마음 문장. 45쌍 매트릭스 없음을 전제로 관계층 규칙 확장형으로 구현.
6. 지역 오행 엔진: 미국=庚申, 중국=戊土, 일본=丙火 매핑 테이블 + 지구 반대편 낮밤 규칙(火 부재 시 반대편 권고) + 水=해외 상징 + 년주 국가자리 룰. 남반구 질의는 반대편 규칙으로 응답하고 용어 차이를 고지.
7. 시주 미상 모드: 학파 규칙 부재(T02-005 유일). 시주 의존 규칙(자녀·61~80세·연하 배우자 등) 비활성화 + 근거 없음 고지를 UI에 명시하는 자체 설계 필요.
8. 용어 가드: 지장간, 십이운성, 왕상휴수사, 월령 용신, 격국, 포태법, 파해, 원진·귀문은 미사용(T01-004~008). 12신살은 생지/왕지/묘지 축 classification으로 재해석(T06-018). 충은 3조(寅申巳亥·子午卯酉·辰戌丑未) 통합 + 고요함을 깨우는 조건부 해석.
9. 운 계층: 대운 10년 근묘화실 + 세운 발생 연도 특정. 월운은 미정의이므로 월 단위 출력은 지양하거나 별도 고지.
10. 미확인 엔트리 가드: 코퍼스 32건 미확인(T05-021 끌어옴 3, T09-001 대운론 등 핵심 포함)은 서비스 문구에 사용 시 출처 상태를 함께 기록.

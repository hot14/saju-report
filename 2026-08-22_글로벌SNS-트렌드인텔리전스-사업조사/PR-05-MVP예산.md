# PR-05 MVP 설계 & 50만원 예산 배분 (기술 분석가 P003)

## 1. MVP 기능 명세
### 포함 (Phase 1)
| 기능 | 설명 | 우선순위 |
|---|---|---|
| 트렌드 피드 취합기 | RSS/JSON 소스 자동 수집 → 스프레드시트/DB 적재 | P0 |
| 급상승 감지 | 전일 대비 언급량 증가율 임계값 알림 | P0 |
| 데일리 브리핑 | LLM 요약 뉴스레터 (무료 리드 유입용) | P0 |
| 위클리 심층 리포트 | 기관급 템플릿 기반 PDF/웹 리포트 (유료 상품) | P0 |
| 신뢰도 태깅 | 소스별 등급(A~D) 자동 부여 | P1 |
| 구독 배포 | 뉴스레터 발송 + Gumroad/Stibee 결제 연동 | P1 |

### 명시적 제외 (Phase 1) — 사유
- 실시간 대시보드 SaaS UI: Phase 3 (구독 30명 확보 전까지 수요 미검증)
- AI 영상 자동 제작: Phase 2 (수익 재투입 필요)
- 인스타/틱톡 실시간 API 수집: 공식 API 비즈니스 계정 한계 (C1) → 2차 소스(랭킹 페이지/뉴스)로 대체
- 중국 SNS 직접 크롤링: 본토 계정/법 리스크 → 공개 랭킹 페이지 + 신뢰도 D 등급 명시 후 채택

## 4. Phase 확장 로드맵
- Phase 2 (+2026-12): AI 콘텐츠 템플릿 패키지, 스크립트 생성기 → 추가 예산 10~20만원(매출 재투입)
- Phase 3 (+2027-02): 셀프서브 대시보드(초대제) → 수익 기반 확장

## 5. 예산 리스크 플랜
- 50% 소진(25만원): 유료 도구 전부 무료 대체(Make→n8n 로컬), 마케팅 실험 중단, 유기적 콘텐츠만
- 80% 소진(40만원): LLM API 최저가 모델 전환, 데이터 소스 축소(핵심 3개), 단발 판매 집중
- 킬 크라이테리아: Phase 1 종료(2026-11 말) 시 유료 판매 0건 & 리드 <100명이면 서비스 피벗(외주 리서치 브랜드로)

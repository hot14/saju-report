실측 발견 사항

  1. F1 · base v1.0 결함 보고(미수정). :lang(en) { hyphens: auto }가 블록 전역으로 선언되어 있다(base §4). 주석과 i18n-spec §4 매트릭스는 "협폭만 auto"를 규정하는데, 선언 자체가 전역이라 프로덕션 en 페이지에서는 본문 어디서나 하이픈이 활성된다. 협폭 한정 규칙(:lang(en).narrow, .narrow :lang(en) p)은 사실상 중복. 표의 en·en-GB hyphens 열 값(auto)이 이 결함의 실측 증거다. 기존 파일 수정 금지 규칙으로 본 데모는 기록만 한다. 수정 방향(참고): 블록 내 선언을 제거하고 narrow 규칙만 남기면 스펙과 일치한다.
  2. F2 · 단일 페이지 호스팅 보정. 데모는 html 이 lang="ko" 고정이라 :lang(ko)가 전 섹션의 조상이 되고, base §6 혼합런 규칙 :lang(ko) :lang(en)(0,2,0)이 en·en-GB 섹션 전체에 적용되며 line-height: inherit(1.8)가 된다. 또 base §3의 line-break: strict 가 ko 이외 섹션에 상속된다. 프로덕션(로케일별 URL · html[lang]=해당 로케일)에서는 발생하지 않는 인위적 충돌이라 head 의 style 블록 마지막 3줄로 프로덕션 계단값을 원복했고, 표의 en 계열 값은 보정 후 실측이다. 프로덕션 영향 없음.
  3. F3 · 디스플레이 행간 de-facto 값. ja·zh·fil·id·ru 의 h3 디스플레이 행간이 본문 행간(1.8/1.6)과 동일하게 실측됐다. 결함이 아니라 i18n-spec §4 각주가 문서화한 v1.1 de-facto 승계(명시 오버라이드는 th 1.3 · vi 1.25 · ko/en 1.15 뿐). 1.15 디스플레이 행간의 전 로케일 복원은 base 소유 과제다(무수정 원칙 · 후속 base 개정 권고).

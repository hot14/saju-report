# 남촌 물상론 상업 이용의 법적 경계 (티켓 #9 리서치)

작성: 2026-10-01 · 성격: 서비스 설계 결정 근거 수집이며 법률 자문이 아니다
조회 방법: 웹 판례 출처(casenote.kr, 대한저작권법학회 칼럼, KCI 논문) + 법제처 CLI(조문 원문 조회는 일시 장애로 보류, 아래 명시)

## 결론 3줄

1. 물상론이라는 이론·체계 자체는 저작권 보호 대상이 아니다. 원리를 공부해 자체 문장으로 해석 콘텐츠를 만드는 것은 원칙적으로 가능하다.
2. 위험한 것은 표현의 복제다. 책의 문장·도표·목차 구성·사례 데이터를 서비스에 옮기는 행동을 금지 규칙으로 고정한다.
3. 학파명 '남촌'은 45류(운세 정보제공업 포함) 등록 상표라 브랜드에 쓰지 않고, 설명 텍스트에서 출처 표기 형식으로만 쓴다.

## 근거

### 아이디어와 표현의 구분 (검증됨)

- 대법원 2000. 10. 24. 선고 99다10813 판결: "표현되어 있는 내용 즉 아이디어나 이론 등의 사상 및 감정 그 자체는 설사 그것이 독창성, 신규성이 있다 하더라도 원칙적으로 저작권의 보호 대상이 되지 않는다." 실질적 유사성 판단도 창작적 표현형식끼리만 대비한다. (출처: casenote.kr/대법원/99다10813)
- 같은 법리의 후속 확인: 대법원 2014다14375 판결 등.
- 국제 조약 차원: TRIPS 협정 제9조 제2항이 "저작권 보호는 표현에는 적용되나 사상, 절차, 운용방법 또는 수학적인 개념 그 자체에는 적용되지 아니한다"고 명문화. (출처: 한국저작권법학회 이호흥 명예회장 칼럼, e-patentnews)
- 법령 근거: 저작권법 제2조 제1호의 저작물 정의(사상 또는 감정을 표현한 창작물). 단, 조문 원문 대조는 법제처 API 일시 장애로 2026-10-01 조회 실패. 게시 전 재조회 필요.

### 경계가 흐려지는 지점 (설계상 주의)

- 합체의 원칙(merger)과 필수장면 원칙: 아이디어를 표현할 방법이 극히 제한적이면 보호 범위가 좁아진다. "10 천간을 자연물에 대응시킨다"는 발상 자체는 남촌 이전에도 널리 존재하는 보편 발상이라 배타적 보호가 약하다. 그러나 김대영 특유의 구체적 정의 문장(예: 특정 천간의 물상 서술)은 표현으로 보호될 수 있다.
- 부정경쟁방지법 경로: 한국 법원은 저작권법상 보호가 애매한 "경계의 창작물"에 대해 부정경쟁방지법 보호나 불법행위책임으로 보호하는 경향이 있다(KCI 논문 2018, 아주법학). 책 제작에 들어간 상당한 투자 결과물(사례집 데이터 등)을 통째로 이용하면 저작권 외 경로로도 문제될 수 있다.

### 상표 (KIPRIS 2026-08-29 실측 완료분 기준)

- '남촌' 상표 2건이 김대영 명의로 등록: 4020210062382(16류 도서), 4020210062383(45류 운세 정보제공 포함).
- 서비스명·앱명·브랜드에는 '남촌'을 쓰지 않는다. 45류는 서비스 업종과 정확히 겹친다.
- 설명 텍스트에서의 학파 인용(예: "본 서비스의 해석 원리는 남촌현대물상론 학파의 공개 강의와 출판물에서 공부한 물상 체계를 독자적으로 재구성한 것입니다")은 사실 표시 형식으로 가능할 여지가 크다. 상표법에는 자기 성명·상호를 보통의 방법으로 질표시로 쓰는 경우 상표권 효력이 미치지 않는다는 규정이 있으나, 조문 번호와 원문 대조는 법제처 API 장애로 보류(게시 전 재조회). 보수적으로는 학파명을 상업 화두가 아니라 출처 표기로만 쓴다.
- 인증·제휴를 암시하는 표현("김대영 공인", "연구회 공식")은 실제 제휴 없이 금지.

### 라이선스 경로 (미확정, 참고)

- 남촌물상역학연구회와 동방문화대학원대학교 평생교육원 강의가 운영 중이라 접점은 존재한다. 다만 공개된 라이선스 프로그램 정보는 확인되지 않았다. 국내에서 타 사주 학파 이론을 기반으로 한 상업 앱이 학파 측 라이선스를 명시적으로 받아 운영하는 공개 사례도 확인되지 않았다(2026-10-01 검색 기준). 이 조사는 후속 여지가 있다.
- 실무 판단: 원리 재구성 방식은 라이선스 없이 진행 가능한 경로로 보이며, 출처 표기 규칙을 지키는 것이 분쟁 예방의 기본이다. 만약 원문 인용형 콘텐츠(책 구절 노출)를 원하면 그때 연구회 접촉을 검토한다.

## 서비스에서 하지 말아야 할 것

1. 책(이론집·사례집) 원문 문장, 도표, 목차 구성을 서비스 화면·카피·마케팅에 그대로 또는 약간의 수정으로 노출하는 것
2. 서비스명·앱 이름·브랜드에 '남촌' 또는 이와 유사한 명칭 사용
3. 사례집의 개인 사례(실명·사주 데이터)를 서비스 콘텐츠나 홍보에 재사용하는 것
4. 실제 제휴 없이 김대영 교수·연구회의 인증·공식성을 암시하는 표현
5. 통합자료집 파일(전문 포함)을 공개 저장소에 커밋하거나 외부에 배포하는 것 (source-namchon/은 gitignore 유지)
6. 해석 문장 생성 시 원문을 프롬프트에 넣고 "다시 쓰기"만 하는 방식(표현적 실질 유사성이 남을 수 있음). 원리 규칙표를 먼저 추출하고 규칙에서 문장을 새로 생성하는 방식으로 간다

## 리스크 등급

- 표현 복제(원문 노출): 상. 설계로 원천 차단.

- 사례 데이터 재사용: 중.
- 출처 표기 방식: 하. 규칙 준수로 관리.

## 1. 사주아이(saju-kid) 구조 분석 — 적용할 것

유료 해설(990원)의 sajuResult는 13섹션 구조다(덤프 키 구조 확인, 본문 미인용):
한마디로 표현하면 → 성격 → 오행으로 보는 사주 → 일주와 십성 → 돈 → 직업 → 이성 → 가족 → 친구 → 지역 → 신랄한 비판 → 따뜻한 위로와 칭찬 → 힘을 주는 문구.

2. 감정 아크 설계: 정보 섹션 뒤에 신랄한 비판(칼끝을 패턴에) → 위로와 칭찬 → 힘을 주는 문구로 끝낸다. 우리 슬롯의 끝1~4(한계를 특성으로/위로)와 정확히 일치 — 오너 설계가 이미 반영.
3. 데이터 모델: members/{mid}/sajuReadings(13섹션)·daewunReport·newYearFortune·goonghaps 분리 저장, 990원 단건 7종, 츄르 경제. 상품 설계 참고(#15).
4. 실측 ARPPU 샘플: 구매 6회·소비 45개(사주해설 22·궁합 15·대운 5) — #15 가격 검증의 실측 데이터로 활용 가능.

## 3. 슬롯 레지스트리 스키마 (service/content/slots.json)

```
{
  meta: { version, source: "docs/pdf 일간별 통병 갈래·슬롯 설계", rules: {...} },
  rules: {
    selection: [우선순위 8단계],
    sentence: [문장 규칙 8종],
    safety: [안전 4종],
    translation: { 자리 4종, 글자 10종 }
  },
  sections: [ 사1~사8, 일1~일7, 재1~재7, 연1~연6, 계1~계5, 끝1~끝4 슬롯 정의 ],
  stems: {
    "甲": { A: { 직업결, 사2, 사3, 사4, 일1, 재6, 연1 }, B: [ { 단계, 조건, 가지, 슬롯, 진단문장, 처방문장, 근거 } ... ] },
    ... 乙~癸
  }
}
```

## 4. 슬롯 엔진 흐름 (항시 적용)

1. 엔진 계산 → 해석표(합·끌어옴·탁수·지지합충·오행집계) 생성
2. 일간 장 로드(A 고정값) → B 갈래 순회하며 해석표와 일치 가지 표시(0-5 우선순위 정렬, 최대 2개)
3. C 운 갈래(지금·앞뒤 10년) 표시
4. 표시 가지 → 슬롯 배치(D 출력 안 함 제외) → 섹션별 문장 출력
5. 검증: 콘텐츠 대응(slots.json+stems.json 대조)·안전 규칙·문장 규칙

## 5. 단계 구현 계획

- 단계 1: slots.json 구축 — 갑목 장 전체(공통 규칙+A+B)를 PDF에서 전사(전량, 근거 번호 유지)
- 단계 2: 을~계 9장 전사
- 단계 3: 슬롯 엔진(app.js) — 해석표→갈래 선택→슬롯 채움, 현재 한눈 요약을 사1~사8 슬롯 출력으로 교체
- 단계 4: 검증기 확장(0-3 문장 규칙 8종) + 스모크
- 단계 5: 배포

안전·법률: 원문 인용 금지 유지, 0-6 안전 규칙은 기존 policy.json 고지와 병행.
윤문 게이트: 경로 light, 엠대시 0, 법령 검증 해당없음

### 우리의 시장 정의
- **TAM**: 글로벌 트렌드 인텔리전스+소셜 리스닝 $11B (2026)
- **SAM**: 한국어 크리에이터·소형마케팅 담당자 대상 저가 셀프서브. 국내 크리에이터 산업 5.55조 원, 수익창출 유튜브 채널 약 10만 개(플레이보드 2020), 창작자 소득신고 34,219명(국세청). 잠재 지불 고객 풀 약 1~3만 명 [D 추정]
- **SOM(7개월)**: 유료 고객 30~150명 × 2~3만원/월 = 매출 100~1,000만원 (PR-08 시나리오와 연동)

## 2. 성장 동인
1. 숏폼·크리에이터 경제 확대: 크리에이터 5,000만 명, 연 10~20% 증가 (GS, A)
2. 저가 셀프서브 공백: Brandwatch/Meltwater는 엔터프라이즈 가격, Exploding Topics/Glimpse는 한국어·중국 커버리지 없음
3. Google Trends 기능 축소 → 대안 도구 수요 유발 (Glimpse 10만+ Chrome 사용자, 평점 4.8이 시장성 입증, B)
4. 마이크로 인플루언서 선호: 마케터 46%+가 팔로워 10만 미만 선호 (C) → 개인 크리에이터의 '데이터 기반 기획' 수요
5. APAC 최고 성장: 소셜 리스닝 내 APAC CAGR 16.57% (Mordor, B)

## 3. 한국 시장 특성
- 양극화: 창작자 하위 50% 평균 연소득 40만 원 vs 상위 1% 평균 7.13억 원 (국세청, A) → 저가 구독($10~20 수준) + 단발 리포트 혼합 과금 필요
- 영세 구조: 종사자 5인 미만 사업체 85.7%, 30대 이하 52.3% (방송위, A) → 1인 운영 도구 성격이 타겟과 일치
- 플랫폼 편중: 유튜브 65.9% / 인스타 12.9% / 네이버클립 7.9% (A) → 모니터링 우선순위 근거
- MZ 구매 영향: MZ세대 72.3%가 인플루언서 추천 경험 (레뷰, B) → B2B(소형 브랜드) 리드 확보 근거

| 배지 2 | 깊은 심목 甲 |
| 배지 3 | 정오 표식 丙 |

## 용어 대응표 (EN ↔ KO)

| EN | KO | 근거 |
|---|---|---|
| Mirror Lake (壬) | 거울 호수 | 壬 = 큰물·거울상 은유 유지 |
| Heartwood (甲) | 깊은 심목 | 甲 = 큰나무·심재(心材) |
| Noon Mark (丙) | 정오 표식 | 丙 = 태양·한낮 |
| THE TEN FORMS | 열 가지 형태 | 십천간(十天干) 컨슈머 표기 |
| SINGLE CARD | 단 하나의 카드 | "The result stays as a single card" 철학 |
| EIGHT LETTERS | 여덟 글자 | 팔주(八字) 컨슈머 표기 |
| READ MY PATTERN | 내 패턴 읽기 | 행동 동사형, 운세 어휘 회피 |

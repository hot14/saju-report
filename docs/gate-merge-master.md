- 대비 실측 수치(먹 on 한지 15.5:1, 골드 필 먹 문자 5.5:1, 골드 텍스트 2.8:1 금지, #A8A29A on 한지 불합격)가 UX 리포트와 tone 가이드에서 독립 계산으로 일치한다. 상호 검증 통과로 본다.

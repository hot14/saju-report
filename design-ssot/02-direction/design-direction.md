# 02 — 디자인 방향 (Design Direction v0.1)

## 1. 베이스 방향 결정 (가설 → 검증 대상)

**"Nocturne Obang" — A(다크 셀레스티얼 에디토리얼) × C(오방색 시스템) 하이브리드**, B(한지 라이트)는 유료 리포트 읽기 모드로 부분 채택.

| 평가축 (가중치) | A 단독 | B 단독 | C 단독 | **A+C** |
|---|---|---|---|---|
| 공유 카드 강도 30% | 상 | 하 | 중 | **상** (다크+골드+오행 도트) |
| 신뢰감 25% | 중 | 상 | 중 | **중상** (에디토리얼 톤 유지) |
| 시스템 확장성 25% | 중 | 중 | 상 | **상** (배지=색=의미) |
| 차별성 20% | 하 (Co-Star 닮음 위험) | 상 | 상 | **상** (오방색은 카테고리 내 유일) |

판정: A+C 승률 최고. **Stitch로 A/C/A+C 3안을 실제로 생성·비교한 뒤 확정**한다 (06-workflow Step 1).

## 2. 컬러 토큰 초안 (다크 프리미엄 조정 오행)

출처: 오방색 체계(정색5+간색) → 다크 웹용 톤 조정 (03-references §5).

| 토큰 | 값 | 기원 | 용도 |
|---|---|---|---|
| `--ink-base` | `#141416` → `#1B1B1E` | 수(黑) 먹색 | 페이지 배경 |
| `--ink-surface` | `#202024` | 먹색 상승 톤 | 카드/섹션 |
| `--hanji` | `#F5F1E6` | 금(白) 한지 백 | 본문 텍스트, 라이트 모드 베이스 |
| `--hanji-muted` | `#A8A29A` | 한지 그레이 | 서브 텍스트 |
| `--wood` | `#2E5A87` (청) | 木 목 | 물상 배지·섹션 컬러 |
| `--fire` | `#B33B24` (적) | 火 화 | 강조 포인트 |
| `--earth` | `#C9A227` (황·금박) | 土 토 | CTA·골드 포인트 (단청 금분) |
| `--metal` | `#C0C6CD` (백금) | 金 금 | 서브 배지·보더 |
| `--water` | `#3B4A6B` (흑청) | 水 수 | 차트·타임라인 |

사용 규칙:
1. 오행 5색은 **물상 배지·도트·공유 카드에만** 집중 적용. 페이지 크롬(배경/텍스트)은 먹+한지 뉴트럴 통제.
2. 골드(`--earth`)는 CTA와 공유 카드 시그니처에만 — 남발 시 저가화.
3. 라이트 모드(B 요소): `--hanji` 베이스 + 먹 텍스트 + 오행 5도트. 유료 리포트 '읽기 모드' 토글.
4. 그레인: 한지 질감 오버레이 (opacity 3-6%) — textured-grains 트렌드 (03-references §4).

## 3. 타이포그래피 (페어링 3본제)

AestheticScout 6세트 중 3개 채택, 역할 분리:

| 역할 | 한글 | 라틴 | 근거 |
|---|---|---|---|
| 히어로/시작/공유카드 | **본명조(Noto Serif KR)** — 한자 그리프 내장 | **Cinzel** | 漢字(壬水·木火土金水) 표기를 단일 폰트로 해결 + 사원 비문 무드 |
| 리포트 본문 | **마루 부리** | **Cormorant** | 온기 있는 명조, 장문 가독 |
| 숫자/라벨/CTA | **마루 부리** | **Italiana** (대형 단문 한정) | 럭셔리 헤어라인 — $8 가격 표기·카드 |

- 한글 폰트: 눈누(https://noonnu.cc) 상업용 무료 라인업에서 최종 확정.
- 한자 온머닌트: 壬癸甲乙丙丁戊己庚辛壬 / 木火土金水 — Noto Serif KR 그리프 사용, 이미지화 금지(텍스트 유지 = SEO·접근성).

## 4. 레이아웃·컴포넌트 시스템

| 컴포넌트 | 정의 | 원리 |
|---|---|---|
| **물상 배지 ×10** | 일간 10종(넓은 물·흙탕물·큰 나무·덩굴·태양·불꽃·산·밭흙·도끼·장식금속 등) — 오행색 도트 + 한자 + 영어 물상명 | P2, R1. 브랜드 최고 자산 |
| **공유 카드** | 1:1/4:5. 배지 + 핵심 한 줄 + 브랜드 시그니처. OG 겸용 | P3, R1 |
| **컷 블록** | 무료 결과 하단 "여기까지가 진단입니다" + 처방 프리뷰 + CTA | R2 |
| **결제 보증 블록** | 3줄 고정 카피 + Apple/Google Pay | P7, R3 |
| **대운 타임라인** | 7번 주제(언제 달라지는가) 전용 컴포넌트 | 차별화 #1 |
| **챕터 내비** | 유료 결과 7주제 진행 인디케이터 | guided scrolling 트렌드 |

레이아웃 문법: 모바일 1컬럼 에디토리얼, 대형 세리프 히어로, 벤토 그리드는 **공유 카드와 결과 요약에만**.

## 5. 모션 원칙

1. **결정론적** — 같은 입력 = 같은 계산 연출 시퀀스 (P1). 랜덤 스피너 금지.
2. '계산 중' = 물상이 조립되는 단계 리빌 (3-4단계, 스킵 가능).
3. 거리·속도 절제 — 200-400ms, ease-out. 글로우 펄스는 공유 카드에 한정.

## 6. Anti-slop 금지 목록 (Stitch 프롬프트에 그대로 주입)

- 카피: fortune, destiny, fate, "the stars say", 십신·격국 등 학파 용어 노출
- 비주얼: 수정구·점성술 원반 클리셰, indigo→violet 그라데이션, 보라색 배지 스팸, 글로우 남발, 3열 아이콘 카드 랜딩, 이모지
- 구조: 로그인 유도, 구독 상품, 광고 슬롯 (설계 문서상 부재 항목)
- 타이포: Inter/Roboto 기본값, 타입 스케일 3단 미만

## 7. 카피 톤 (The Pattern 벤치마크)

"patterns shaping your life" — 구조는 단정, 미래는 조건문. 예시 어휘: pattern, tendency, the way you're built, thrive in, drawn to. 금지 어휘는 §6. 무료 샘플 문장(설계 문서 §5)이 톤의 정답지.

## 0. 전제 요약 5줄

1. 제품은 6화면 웹 퍼널(R-02)과 공유카드(R-42)뿐이다. 채널 전략은 화면을 늘리는 것이 아니라 **같은 랜딩이 채널별 기대를 흡수하는 방식**의 문제다.
2. 북극성 지표는 조회수가 아니라 **Qualified Chart Completion**(정확한 생년월일 입력 후 결과를 실제로 본 사람, SajuRoot 레드팀 승계)이다. 채널 성과는 전부 이 지표로 환산해 비교한다.
3. 어휘는 3층으로 운용한다(§2): 화면 카피는 금지어 체계 유지, 검색 메타는 "korean astrology" 계열 하향 허용(R-32), 채널 사이드 자산은 조건부. 금지어 정책과 발견 전략의 양립 답변(D-A4)이 이 3층이다.
4. 브랜딩 4축 판정: 네이밍 **SajuRoot 임정 유지(승인 권고)** · 시그니처 컬러 **골드 #B98A2C(시그니처 한정)** · 보이스 **카피덱 게이트의 채널 변주** · 로고 **A안 기본 + C안 확장 + B안 대형 한정**(logo-concept-spec 권고를 채널 효과로 재확인).
5. 재유입은 공유카드 루프백("Read your own" + URL, 9:16은 QR)이 유일한 엔진이다(P3). 채널별 차이는 루프백 카드의 노출 지점과 크기뿐이다.

## 1. 공통 퍼널 골격 (5단계)

| 단계 | 정의 | 자산 | 규칙 |
|---|---|---|---|
| 1 진입 | 채널 접점에서 첫 클릭 | 채널별 훅 자산(§3) · UTM | utm_source·utm_campaign만 허용. 개인정보 파라미터 금지 승계 |
| 2 랜딩 | 첫 화면 3초 인지 | 랜딩 화면(공통) + 채널 정합 라인(§4 제안) | 화면 추가 아님. 카피덱 확장 키로만 제안 |
| 3 무료 진단 | 입력 → 정체성 카드 즉시 출력(R-09) | 10 일간 배지({{BADGE}}) · 진단 3문장 | 시각 모름 1급 옵션 노출(R-07) · 계산 리빌 3~4초 |
| 4 처방 | 컷 블록 → 결제 → 7챕터 | 컷 블록 · 보증 3줄 · {{PRICE}} | 랜딩·무료 구간에 가격 노출 0(카피덱 준수) |

계측(승계 권고): 쿠키리스 1st-party 이벤트 6종 `channel_entry · chart_submit · qcc · cut_pass · pay_done · share_made`(grill Q12 잠정 답변과 정합). 개인 식별 결합 없음.

## 2. 어휘 3층 정책 (금지어 체계 × 발견 전략의 양립)

| 층 | 적용면 | 허용 어휘 | 근거 |
|---|---|---|---|
| T1 화면 | 랜딩·결과·카드·CTA 등 사용자 노출 카피 | 금지어 체계 엄수(fortune·destiny·fate·점술 무드 0). "birth chart · pattern · reading · letters" 계열만 | R-29 · 카피덱 게이트 |
| T2 검색 메타 | title·description·og 태그·핀 설명·영상 태그 | "korean astrology · saju · korean birth chart" 허용. 약속한 단어는 랜딩 상단 라벨("Your Korean birth chart, explained clearly.")로 정합 | R-32 하향 규칙 |
| T3 채널 사이드 | 채널 자막·캡션·커뮤니티 본문(우리가 작성하는 분) | T1 문체 유지 + 채널 관용어(해시태그·이모지 절제). 점술 단어는 태그·메타 설명으로만 | 본 문서 권고(채널별 §3에 명시) |

운용 원칙: 채널에서 T2 어휘로 유입된 사람이 화면에서 그 단어를 못 찾으면 반송한다. 그래서 랜딩 상단 라벨이 T2 정합 창구다(§4 검색 행 참조).

## 3. 채널별 퍼널 설계

### 3.1 TikTok (발견 엔진 1번 · K컬처 팬덤 상단)

- **진입 자산**: 15~45초 쇼츠. 문법은 "물상 배지 카드 리빌" 1종(촬영 아님, 제품 화면 녹화 + 먹선 카드). 훅 예시(T3): "Your Korean birth chart calls you a wide lake." · "Ten forms. One is yours from birth."
- **훅 → 랜딩**: 프로필 링크와 카드 루프백 QR. 랜딩 도달 목표는 시청자의 1~3%(쇼츠 발견 특성상 낮음을 전제).
- **무료 → 처방**: 진단 3문장에서 "나 이야기" 몰입이 일어나는 지점이 컷 블록. 영상에서 배지 카드 퀄리티를 본 시청자는 결과 카드 기대치가 높아 진입 시점부터 QCC 전환율이 우위다.
- **재유입**: 9:16 카드의 QR. 틱톡 스토리 재게시용 카드 키트(혼빛 share 키트 선례 승계, 밝은 한지 버전).
- **지표**: 3초 유지 → 링크 클릭 → QCC. 보조: 카드 저장 수.
- **리스크**: 점술 해시태그(#astrology 등)는 T2로 태그에만. 영상 자막에 금지어 노출 시 게이트 위반이다.

### 3.2 Instagram (미적 신뢰 · 카드 미학의 쇼룸)

- **진입 자산**: 4:5 카드 캐러셀(배지 10종 소개 · 계열 통일 먹선 일러스트) + 9:16 스토리 키트. 캡션은 배지 한 줄 선언문(카피덱 §9 EN판) 재사용.
- **훅 → 랜딩**: 스토리 링크 스티커 · 바이오 링크. 카드 프리뷰 문구("The result stays as a single card.")가 랜딩의 카드 프리뷰 섹션과 1:1 정합(카피덱 랜딩 행 승계).
- **무료 → 처방**: IG 유입자는 "결과물이 예쁜가"를 먼저 확인한다. 정체성 카드가 첫 화면 최상단(R-09)인 구조가 그대로 전환 장치다.
- **재유입**: 공유카드가 스토리 언급·DM 공유로 회류. 인앱 브라우저 기준 375px 조판이 실제 주 전면(R-01 정합).
- **지표**: 저장률 → 링크 클릭 → QCC.
- **리스크**: 카드 미학이 피드에서 어둡거나 네온이면 혼빛과 혼동된다. 한지 + 잉크 밴드 이중 구조 유지(share-card-v2-spec §8 승계).

### 3.3 Pinterest (롱테일 SEO · 미드퀄 유입)

- **진입 자산**: 세로 2:3 핀. 핀 이미지 = 공유카드 변형(배지 + 한 줄 + 시그니처). 핀 제목·설명은 T2("Korean birth chart, explained with the method shown.")로 검색 수요를 흡수.
- **훅 → 랜딩**: 핀 클릭 → 랜딩. 핀이 약속한 것은 "설명형 무료 차트"이므로 랜딩 상단 라벨과 정합.
- **무료 → 처방**: Pinterest 유입자는 조급하지 않다(저장 후 방문). "여덟 글자" 서사가 담긴 마무리 섹션이 2차 클릭을 만든다.
- **재유입**: 핀 자체가 공유카드의 영구 게시판. 핀 저장 = 무료 재노출(클릭 없는 인상도 누적).
- **지표**: 핀 저장 → 아웃바운드 클릭 → QCC.
- **리스크**: 핀 이미지에 골드 글로우·오라를 넣으면 T1 시각 금지(R-22 위험)와 미학 균열이 동시에 온다. 골드는 도트·밴드 시그니처뿐.

### 3.4 YouTube (신뢰 엔진 · 회의적 다수의 관문)

- **진입 자산**: 쇼츠(발견) + 롱폼(신뢰) 2층(레드팀 채널 3층 승계). 롱폼 문법: 계산 과정 공개(절기·진태양시 보정 화면), 8글자가 만들어지는 화면 녹화, "다른 계산기와 왜 다른가" 소재.
- **훅 → 랜딩**: 설명란 링크(T2 문장과 함께) · 엔드카드. 롱폼 시청자는 이미 "Method you can inspect"를 영상에서 봤다(3단 스토리 승계).
- **무료 → 처방**: Chart basis 카드(무료 결과 내 근거 표기, R-11)가 영상 약속의 실물 증명. 회의론 대응은 경계 긋기 문장("traditional interpretive practice" 계열, 레드팀 규칙)으로 화면 밖 콘텐츠에서 먼저 수행.
- **재유입**: 엔드카드 QR + 카드 이미지 커뮤니티 탭 게시.
- **지표**: 시청 → 설명란 클릭 → QCC. 롱폼 경유 QCC가 직접 유입보다 결제 전환율이 높을 것이라는 가설을 계측으로 검증(채널별 처방 단계 전환 대비).
- **리스크**: 영상 썸네일에 점술 아이콘(수정구·별) 사용 금지. 먹선 배지가 썸네일 문법이다.

### 3.5 검색 (의도 정합 · 전환율 최고 · 물량 최소)

- **진입 자산**: T2 메타. 예시 description: "Your Korean birth chart, explained clearly. The timezone, solar-term boundary, and method behind every result. Free to read."(레드팀 랜딩 문구 승계, 금지어 0).
- **훅 → 랜딩**: 쿼리 의도 2종("korean astrology/saju" 개념형 · "korean birth chart free" 실행형) 모두 상단 라벨이 정합 창구가 된다.
- **무료 → 처방**: 실행형 키워드 유입자는 즉시 입력으로 간다. 랜딩 4요소(워드마크·라벨·서브·CTA)를 건드리지 않는 것이 전환율 보존이다(§4 히어로 스택 규칙 승계).
- **재유입**: 검색 유입자의 재방문은 브랜드 검색("sajuroot")으로 나타난다. 데이원 브랜드 검색량 0이므로 제네릭 쿼리 선점이 먼저다.
- **지표**: SERP 노출 → 클릭 → QCC(채널 중 최고 전환 기대).
- **리스크**: 메타가 약속한 어휘(astrology)가 화면에 0이면 반송. 상단 라벨 유지가 정합 장치(§2 T2 원칙).

### 3.6 커뮤니티 · Reddit (신뢰 사전 검증 · 최고 위험 최고 보상)

- **진입 자산**: 도구 소개 게시물 1종(텍스트 + 카드 1장). 문법: "만들었음 · 계산 방식 공개 · 면책 · 무료 진단 · 결제는 그 다음" 순서. 프로모션 프레임 0.
- **훅 → 랜딩**: 본문 링크. Reddit 유입자는 광고 회의론이 최강이므로 랜딩에서 마케팅 문구가 먼저 보이면 즉시 이탈한다. 카피덱 랜딩에는 가격·수치·긴급성이 0이라(가짜 긴급성 금지 승계) 구조적으로 정합한다.
- **무료 → 처방**: "다른 계산기와 왜 다른가" · ±40분 경계 카드 같은 투명성 자산이 커뮤니티 검증 논쟁에서 방패가 된다(포스텔러 만세력 투명성 선례 승계).
- **재유입**: 카드 공유는 커뮤니티 규칙 위반 소지가 있어 자연 발생만 허용. 억지 홍보 계획 금지(위 리스크).
- **지표**: 업보트 → 클릭 → QCC. 부정 댓글 대응 스크립트(경계 긋기 문장) 별도 준비.
- **리스크**: astroturfing(가짜 사용자 게시) 적발 시 브랜드 치명타. 운영자 공개 계정 1개로만 활동.

## 4. 썸네일 약속 정합: 채널별 첫 화면 기대

원칙: **채널 자산이 약속한 것을 랜딩 첫 3초가 보여줘야 한다.** 정합 실패의 일반 양상은 (a) 어휘 불일치(메타가 말한 단어가 없음) (b) 무드 불일치(영상 카드는 밝은데 랜딩이 어두움·반대) (c) 노출 불일치(가격·마케팅이 먼저 보임) 3종이다.

| 채널 | 썸네일·메타가 약속한 것 | 랜딩 첫 화면이 보여줄 것 | 정합 실패 시 이탈 모드 |
|---|---|---|---|
| TikTok | "즉각적 배지 카드 · 예쁜 결과물" | 배지 스트립 3종 + 예시 배지(카피덱 랜딩 구성 승계)가 첫 화면에 노출 | 무드 불일치: 영상 카드와 랜딩 톤 위화 → 즉시 이탈 |
| Instagram | "카드 미학 · 저장할 결과물" | 카드 프리뷰 섹션 상단 가시 + 4:5 카드 실물 | 결과물 기대 미달 → 스크롤 이탈 |
| Pinterest | "설명형 무료 차트 · 한국 미학" | 상단 라벨 정합 + 한지 무드 유지 + CTA "Read my pattern" | 어휘·무드 이중 불일치 → 반송 |
| YouTube | "계산 과정 공개 · 신뢰" | 상단 라벨(explained clearly) + 서브의 메서드 문장 | 투명성 약속 미이행 → 회의 확정 |
| 검색 | 쿼리 의표 단어 그대로 | 메타 단어와 라벨의 1:1 대응 | 어휘 불일치 → 반송(가장 흔한 실패) |
| Reddit | "상업적이지 않은 투명 도구" | 무료 진단 명시 + 마케팅 문구 0 + 면책 푸터 | 노출 불일치(판매 냄새) → 신뢰 붕괴 + 부정 댓글 |

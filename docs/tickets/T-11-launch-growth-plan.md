# T-11 · 출시 그로스 계획 (U15·U16·X5 잔여)

> 상태: open · 우선순위: **P3**(출시 로드맵) · 담당 후보: UX + 프로덕트 · 예상: 1d(CTO U15 승계) · 소스: ux-validation-report Q2·Q3 + X5 + 악마 A4 · GitHub: hot14/saju-report#1 연계
> Design Read: 공유 카드 중심의 바이럴 루프에 발신단(시딩·발견) 전략을 더하는 그로스 계획, with 금지어 체계와 양립하는 발견 전략이라는 미해결 질문에 대한 답을 필수 산출물로.

## 배경

- 스크린샷이 유일한 확산 수단(product-analysis 팩트)인데 데이원(공유할 사용자 0명) 상태의 첫 유입 전략이 문서 어디에도 없다(Q2). 카드 수신단 루프백은 share-card-v2-spec.md §7로 해소됐으나 발신단이 없다(악마 A4).
- 가짜 사회적 증거 금지(Q3)의 대체 재료로 샘플 차트 프리뷰(실제 계산 예시 1건) 설계가 남았다(U16).
- X5 잔여: KR 히어로 서브 "짧은 영상은 하루의 글자를 알려줍니다"는 특정 채널 전제 문장. EN 덱은 채널 중립형으로 우회 번역했으나 KR 원문의 유지 여부는 그로스 전략 확정 시 재판정 대상.

## 범위

- 할 것: 신규 `docs/launch-growth-plan.md` 생성. 유입 채널·신뢰 대체 재료·KR 서브 재판정.
- 하지 않을 것: 카피 덱 직접 수정. 성과 수치 목표 설정(지어내기 금지, 카피 룰 8 승계).

## 수용조건

- [ ] 데이원 유입 채널 계획: K-pop 커뮤니티 시딩·크리에이터 협업 등 후보와 우선순위
- [ ] **금지어 체계와 양립하는 발견(SEO) 전략 답변 포함**: 점성·운세 키워드 없이 해외 사용자가 이 서비스를 발견하는 경로(검색 메타 하향 이동 규칙·U4 정합)
- [ ] 샘플 차트 프리뷰 설계: 실제 계산 가능한 예시 입력 기반, 개인정보 0노출(P3 게이트)
- [ ] X5 재판정: KR 히어로 서브의 채널 중립화 여부 + 근거(전략과 연동)
- [ ] 북극성 지표 제안: 조회수가 아닌 Qualified Chart Completion 계열(competitor-intel 승계)
- [ ] 문서 em-dash 0건·금지어 0건

## 체크리스트

- [ ] 채널별 금지어 리스크 점검(커뮤니티 규정·스팸 인식)
- [ ] 카드 루프백 URL(share-card §7)과 채널별 UTM 체계 정합
- [ ] 샘플 차트의 배지는 카피 덱 예시(임수) 준용 검토

## 2. 자동화 스택 설계 (텍스트 다이어그램)
```
[소스] RSS/JSON ──> [수집기] Cloudflare Workers cron (15분~12h 스케줄)
                              │
                              v
                    [저장소] Supabase 무료티어 (신호 테이블)
                              │
                              v
                    [가공] LLM API (Gemini Flash) : 중복제거/한국어 요약/카테고리/신뢰도 태깅
                              │
                    ┌─────────┴─────────┐
                    v                   v
            [데일리 브리핑]        [급상승 알림]
            뉴스레터 발송          Telegram/이메일
            (Stibee 무료티어)      (T+6h SLA)
                    │
                    v
            [위클리 리포트] 템플릿 기반 자동 집계 + 편집 (수동 감수) → PDF/웹
```

## 3. 신호 가공 규칙
1. 중복 제거: URL 정규화 + 제목 유사도 0.85 이상 병합
2. 급상승 감지: 키워드/링크별 24h 언급 수 ≥ 3 소스 AND 전일 대비 ≥ +150% → 이머징 플래그
3. 한국어 요약: 신호당 2문장 (무엇이/왜 중요)
4. 신뢰도 태깅: 소스 테이블 등급 상속 + 교차 확인 시 +1등급

## 4. SLA 달성 검증
- T+6h: 급상승 감지(15분 폴링) → LLM 가공(~5분) → 알림. 최악 배치 지연 감안 T+1h 실측 예상, 목표 T+6h 여유 확보 ✅
- 데일리 08:00 KST: 06:00 배치 집계 → 자동 생성 → 수동 감수(30분) → 08:00 발송 ✅
- 위클리 월요일: 일요일 23:00 데이터 컷오프 → 월요일 편집 발행 ✅

## 5. 장애 대응 (fallback 우선순위)
소스 차단 시: 동일 카테고리 차선 소스 자동 승격. Reddit 차단 → HN/커뮤니티 유사 서브레딧. Google News 장애 → Bing News RSS. LLM 장애 → 규칙 기반 요약(첫 문장 추출) 후 재시도.

## 6. 확장 계획 (수익 후 유료 전환 순서)
1순위 X API Basic (월 $200): 리드 500명+월 매출 100만원 도달 시
2순위 서드파티 인스타/틱톡 애그리게이터: 구독 20명+
3순위 중국 SNS 유료 데이터: B2B 맞춤 리서치 수주 시
